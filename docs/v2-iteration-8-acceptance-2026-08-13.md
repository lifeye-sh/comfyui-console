# V2 Iteration 8 验收记录（2026-08-13）

## 本轮目标

补齐 V2 的真实业务闭环，结束主要菜单仍跳转占位页的状态，使 V2 可以按生成类型动态创建、批量提交并跟踪任务。

## 本轮交付

- 新增 V2 动态生成页面 `/v2/generate/:code`：读取生成类型的已发布配置、工作流绑定和输出定义。
- 尚未发布 V2 配置的生成类型使用 V1 参数模板兼容配置，并在页面明确标识。
- 参数控件支持文本、整数、小数、开关、下拉、随机种子、图片、视频和音频。
- 多媒体参数统一从带目录树的素材库选择，也可在选择器中上传。
- 图片和视频宽高合并为尺寸选择，使用系统维护项及当前默认值。
- 每行可单独选择本类型工作流、复制、删除、生成；支持多行批量提交和保存草稿。
- 文生图提示词导入按“一行一条”解析，支持追加或替换，其他字段使用页面默认参数。
- 动作迁移生成页移除提示词和时长，参数方案统一选择；跳过秒数、多参开关和多参图数仍在任务行维护。
- 任务状态通过 WebSocket 事件和两秒轮询更新；成功后显示全部输出并支持媒体放大预览。
- 新增 V2 原生动作迁移参数方案、用户与权限、审计日志页面。
- V2 工作流管理和系统设置接入现有完整功能，移除所有正式菜单中的占位路由。
- 选择项读取权限调整为所有登录用户，普通用户生成页也能得到尺寸、帧数和帧率默认值。

# V2 Iteration 3 验收记录（2026-08-13）

## 本轮交付

- 无限级素材目录树，支持逐级折叠、展开和默认当天定位。
- 任务结果目录统一为“任务结果/月份/日期/任务 ID-任务类型”。
- 图片、视频首帧和音频媒体卡片网格。

- 普通目录新建、重命名、删除，素材单选/批量选择与移动。
- 图片、视频和音频上传并归入当前目录。
- 素材详情显示文件信息、来源任务、工作流版本和完整生成参数。
- 图片缩放拖动、视频播放、音频播放继续复用统一媒体查看器。
- 通用 AssetPicker 支持类型约束、目录、搜索、上传、单选和多选。
- V2 参考视频页面支持上传、首帧预览和按间隔抽帧。
- V2 提示词库支持分类、查询、新建、编辑和删除。
- V2 回收站支持本人已删除素材查询和恢复。

## 权限与兼容性

- 普通用户回收站数据按本人过滤，不能恢复其他用户素材。
- 视频抽帧增加素材所属用户校验。
- 管理员保留查看全部回收站和彻底删除能力。
- 不新增数据库表或字段；已有日期目录会在归档时兼容迁移到月份目录。

## 验收命令

```powershell
cd backend
pytest -q

cd ..\frontend
npm run typecheck
npm run build
```

## 验收标准

- 登录后可以访问 `/v2/drama/projects` 和 `/v2/drama/new`。
- 未登录访问状态接口返回 401。
- 登录后状态接口返回版本 `2.1`、阶段 `foundation` 和能力开放状态。
- 关闭前端短剧开关后菜单消失，直接访问模块路由返回 V2 首页。
- 关闭后端短剧开关后项目页显示模块关闭说明，不允许进入创建流程。
- 现有 V1/V2 页面、任务调度和素材功能不受影响。

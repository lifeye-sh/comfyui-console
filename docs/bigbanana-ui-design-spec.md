## 1. 设计目标

- 用户始终知道当前处于哪个项目、哪一集、哪个生产阶段。
- 从剧本到成片保持线性主路径，同时允许从项目侧栏直接跳转。
- 生成操作都遵循“准备素材 → 检查提示词和参数 → 提交任务 → 查看版本 → 采用结果”。
- 图片、视频、音频统一使用素材库和 Take 版本，不出现重复上传或孤立结果。
- 默认界面接近 BigBanana 的轻量、米白、细边框风格；支持完整暗色主题。
- 不向普通创作者暴露 ComfyUI 节点编号、API JSON、供应商密钥等底层概念。

## 2. 总体界面框架

### 2.1 两级工作空间

平台存在两种页面状态：

1. **项目库状态**：采用 BigBanana 的全宽、无侧栏项目库；通过“返回首页”回到 `comfyui-console` 平台首页。
2. **项目工作区状态**：进入项目后切换为沉浸式项目壳层，一套项目侧栏贯穿剧本、角色场景、导演、交付和提示词页面。

项目工作区不再同时显示旧平台大侧栏和第二套完整侧栏。左上角提供“返回平台/返回项目库”，既避免双侧栏，也保留平台归属。

### 2.2 桌面布局

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 项目侧栏 248 │ 顶部上下文栏 64：项目 / 集数 / 保存状态 / 快捷操作     │
│              ├──────────────────────────────────────────────────────┤
│ 返回项目库    │                                                      │
│ 项目名称      │                 页面主内容区                          │
│ 当前第 1 集   │                                                      │
│              │                                                      │
│ 剧本与故事    │                                                      │
│ 角色与场景    │                                                      │
│ 导演工作台    │                                                      │
│ 成片与导出    │                                                      │
│ 提示词管理    │                                                      │
│              │                                                      │
│ 素材库/日志   │                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

- 项目侧栏：248 px；允许折叠为 72 px 图标栏。
- 顶部上下文栏：64 px，滚动时固定。
- 主内容：24 px 外边距；导演工作台可使用全宽。
- 右侧详情抽屉：360–420 px；打开后压缩主区，不覆盖关键镜头内容。
- 断点：≥1440 完整三栏；1024–1439 右抽屉覆盖；<1024 使用单栏和底部导航。

### 2.3 项目侧栏

顶部区域：

- 返回项目库。
- 项目名称，单行省略；悬停显示全名。
- 当前集选择器，例如“第 1 集 / 共 12 集”。
- 当前集完成度和 5 个阶段圆点。

主导航：

1. 剧本策划
2. 视觉设定
3. 导演工作台
4. 剪辑交付
5. 提示词库

辅助入口：素材库、任务日志、项目设置。底部保留主题切换和帮助，不显示账号、充值或余额。

### 2.4 顶部上下文栏

左侧显示面包屑与页面标题；中间仅在需要时出现状态；右侧最多保留一个主操作和两个次操作。

全局状态：

- `已保存`：静态文字。
- `保存中…`：旋转图标，不阻止继续编辑。
- `保存失败`：红色状态和“重试”。
- `后台任务 3`：点击打开当前项目任务抽屉。
- `存在 2 个阻断项`：点击定位到未准备镜头。

## 3. 视觉规范

### 3.1 色彩

亮色主题：

| 用途 | 建议值 |
| --- | --- |
| 页面背景 | `#F8F7F4` |
| 主表面 | `#FFFFFF` |
| 次表面 | `#F3F0EA` |
| 主文字 | `#22211F` |
| 次文字 | `#706C66` |
| 边框 | `#E3DED5` |
| 品牌强调 | `#A98758` |
| 选中深色 | `#232220` |
| 成功 | `#3D7B58` |
| 警告 | `#B77932` |
| 失败 | `#B84C4C` |

暗色主题采用同一语义反转，不直接沿用现有 V2 的高饱和蓝紫渐变。生成任务状态可以使用平台公共状态色，但大面积背景保持中性。

### 3.2 排版与密度

- 字体：系统中文无衬线栈；数字、任务 ID 和变量名使用等宽字体。
- 页面标题：28 px/600；区块标题：18 px/600；正文：14 px；说明：12 px。
- 8 px 间距网格；页面区块间隔 24 px；卡片内边距 16 px。
- 普通卡片圆角 12 px；弹窗和抽屉 16 px；表单控件 9 px。
- 阴影只用于浮层、抽屉和拖拽态，普通卡片用边框区分。

### 3.3 通用组件

- `DramaProjectShell`：项目侧栏、顶部上下文栏、任务抽屉。
- `StageProgress`：五阶段准备度。
- `MediaAssetCard`：图片/视频/音频统一卡片。
- `VersionStrip`：Take 缩略图、版本号、采用状态和历史切换。
- `CapabilitySelector`：业务动作到已发布工作流的选择器。
- `GenerationPanel`：提示词、输入素材、参数、能力卡、提交按钮。
- `JobStatusBar`：排队、生成中、失败、成功及重试。
- `BlockingIssueList`：生成前阻断项及跳转修复。
- `AssetPickerDrawer`：复用素材库目录和筛选能力。
- `PromptEditor`：变量标签、正文、预览编译、恢复默认。

## 4. 页面一：漫剧首页 / 项目库

路由：`/v2/drama`

### 4.1 页面结构

实站采用全宽、无侧栏结构：

```text
项目库 / Projects Database      中文/English  返回首页  新建项目  图标操作
说明文案
项目数  最近 7 天活跃  素材数
────────────────────────────────────────────────────────────

继续最近项目（左侧大区）                       快速查找项目（右侧窄区）
项目标题、更新时间、资产数                    搜索框
最近编辑 / 角色场景道具 / 项目概况             最近 3 个项目
继续编辑  新建项目  浏览全部项目               查看全部  系统设置

全部项目  显示 n/n
说明文案
项目卡片列表
```

页面最大内容宽度约 1180–1240 px，居中显示；背景为 `#F7F5F0`，标题采用较轻字重。顶部统计使用紧凑胶囊，不使用大型 KPI 卡。项目库重点是“继续最近项目”，不是数据看板。

项目卡片不强制使用封面。实站默认用文件夹图标、标题、描述、角色/场景/道具数量、最近编辑时间和创建日期；有封面时可以渐进增强，但不能让缺少封面的项目出现破损占位。

空状态显示“开始你的第一个项目”、主说明和“新建第一个项目”；下方仍保留快速查找和全部项目骨架。任务数量来自现有 Task 查询，素材数量来自 Resource 引用统计。

### 4.2 新建项目动作

参考实站，“新建项目”是快速动作，不先展示复杂表单：

1. 点击后立即创建默认项目和“第 1 集”。
2. 默认名称为“新建项目 + 时间”，状态为“完善中”。
3. 创建成功后直接进入项目总览。
4. 项目名称、语言、比例、目标时长和视觉风格在项目设置或剧本策划中继续完善。

为避免误创建，`comfyui-console` 版本可在按钮旁提供下拉：主按钮仍为“一键新建”，次选项为“导入整篇小说”“导入项目工程”。不得恢复成创建前必须完成的三步向导。

## 5. 页面二：新建后的项目总览与整篇小说导入

路由：`/v2/drama/projects/:projectId`

### 5.1 项目总览

实站新项目总览采用“先创作、后补资源”的引导顺序：

- 顶部返回项目列表；显示“完善中”、项目完整度、已完成阶段和项目标题。
- 左侧主卡显示项目说明、创建时间、项目进度、剧集/集数/角色/场景/道具/世界观状态，以及“导入整篇小说”“导出整项目”。
- 右侧推荐下一步卡突出“先开始第 1 集剧本策划与分镜”，主按钮为“进入剧本策划”。
- 第二屏是资源工作台：角色、场景、道具、剧集结构、世界观五个入口。
- 第三屏是剧集管理：季、集数、新建剧集、添加新集、删除剧集和进入单集。

不在新建后立即要求用户填写全部角色和世界观。角色、场景、道具由分镜需求反推或按需补充；世界观为可选增强项。

### 5.2 导入整篇小说

导入区支持拖放 `.txt/.docx/.md`、粘贴文本和从素材库选择文本文件。流程状态：

```text
上传 → 解析章节 → AI 分析 → 拆集建议 → 人工确认 → 写入剧本
```

拆集结果采用表格：集号、章节范围、标题、核心冲突、预计时长。支持拖动调整分界、合并、拆分、忽略某集。点击“确认并创建分集”前不修改正式 Episode。

## 6. 页面三：剧本与故事

路由：`/v2/drama/projects/:projectId/episodes/:episodeId/script`

### 6.1 实站双工作区布局

第 1 集实站不是“集列表 + 编辑器 + 参数抽屉”三栏，而是在 288 px 全局导航侧栏右侧继续拆为两个工作区：

- 固定项目配置栏约 376 px：标题、创作模式、输出语言、画幅、目标时长、分镜模型、视觉风格、质量控制和生成入口；配置内容可独立纵向滚动，底部主操作固定可见。
- 剧本编辑区占剩余宽度：顶部固定 AI 工具条，中部为模式说明与大文本编辑器，底部固定显示长度、字数、行数和自动保存状态。

导航侧栏显示当前项目、当前集数和五个生产阶段：剧本策划、视觉设定、镜头设计、剪辑交付、提示词库。集数切换不占用正文编辑宽度。

结构化场次/对白块属于“生成分镜脚本”后的下一阶段；初始剧本策划页保持纯文本输入，避免用户在故事尚未稳定时被迫处理镜头字段。

### 6.2 核心操作

- AI 续写：从光标或所选场次继续，结果作为候选差异显示。
- AI 改写：提供全文改写与选段改写；选段改写在未选择正文时禁用，工具条明确显示“请先在下方选择段落”。
- 撤回改写：仅在存在可撤销的 AI 修改时可用。
- 自定义改写要求：工具条下方保留单行输入，如“更紧张、增加冲突、对白更口语化”。
- 参数设置：创作模式、语言、画幅、目标时长、视觉风格、分镜模型绑定。
- 反推风格：从上传参考图或素材库图片分析，生成可编辑建议，不直接覆盖项目风格。
- 生成分镜脚本：提交后台 CreativeJob；完成后直接进入正式的“拍摄清单（Script Manifest）”结果页，不停留在弹窗候选；页面不要求生成期间保持打开。
- 全自动模式：打开计划弹窗，显示会生成和会跳过的对象数量。

### 6.3 项目配置控件

- 项目标题：默认“第 1 集”，直接编辑并自动保存。
- 生成分镜模式采用二选一，界面标签准确使用：`小说生成分镜` 与 `分镜生成分镜`。第二项的产品语义是“已有分镜模式”，但不在按钮内增加“已有”二字。
  - 小说生成分镜：适用于用户只有小说、章节正文、剧情大纲或剧本，还没有自行制作分镜的情况。系统负责理解故事、拆分场次、规划镜头和补齐镜头字段。
  - 分镜生成分镜：适用于用户已经按照自己的导演理解完成分镜。系统以用户分镜为主进行结构化、校验和能力补全，不擅自改变镜头顺序、对白、任务动作和镜头备注，因此能够获得更强的一致性。
- 左栏模式帮助文案随选择切换：小说模式提示“标准模式适合直接粘贴小说、章节正文或剧情大纲，由系统先理解故事，再自动拆成镜头。”；分镜模式提示“高级模式会尽量按你已经写好的分镜逐条生成，优先保留镜头顺序、对白、任务动作和镜头备注。”
- 两个模式是输入路径，不是质量档位。切换模式必须同步替换说明、输入占位、推荐输入、字段校验和生成策略。
- 画面比例：横屏、竖屏。切换会成为角色、场景、分镜和视频的项目默认比例，并在确认前提示影响范围。
- 目标时长：30 秒、60 秒、2 分钟、5 分钟、自定义；下方实时显示当前秒数、按视频工作流默认单镜时长估算的镜头数，以及对叙事节奏的提示。
- 分镜生成模型：选择文本/多模态模型，显示模型说明、内部 ID 和“到模型配置添加模型”的入口；此处复用 comfyui-console 的模型注册表。
- 视觉风格：日式动漫、2D 动画、3D 动画、赛博朋克、油画、真人影视、自定义；选中后显示参考缩略图，支持点击放大。
- 上传图片反推风格：支持本地上传和从素材库选择；输出候选风格提示词，确认后才写入 Style Bible。
- 质量控制：默认开启“分镜质量校验与自动修复”，校验字段缺失、关键帧结构、素材 ID 和工作流能力匹配。
- 系统通知：生成前展示当前通知/拦截状态，但不混入账号或付费信息。

### 6.4 编辑器状态与约束

- 空态包含创作模式标签、模式说明、推荐输入类型和大号输入提示。
- 小说模式使用绿色状态标签“小说生成分镜”；说明为“系统会先理解故事结构，再自动拆成适合当前时长和节奏的分镜。”；推荐输入为章节原文、剧情大纲、角色目标、冲突节点和高潮转折；正文占位为“在此输入故事大纲、章节正文或直接粘贴剧本…” 。
- 分镜模式使用暖黄色状态标签“分镜生成分镜”；说明为“系统会优先把你已写的镜头块转成结构化分镜，尽量保留原有顺序、对白、任务动作和镜头备注，只在缺字段时做最小补全。”；正文占位为“在此粘贴你已经写好的分镜脚本，建议按下方模板填写场景、镜头动作、对白和镜头备注…” 。
- 分镜模式空态必须展示两个并排模板：`模板 A · 标准分镜` 和 `模板 B · 对话驱动`。模板不是可选生成风格，而是可以直接照抄的输入格式示例。
- 标准分镜模板字段：场景标题、分镜编号、画面、动作任务、对白、镜头备注；适合完整镜头设计。
- 对话驱动模板字段相同，但允许以对白为主、镜头说明较短；系统只补齐必要镜头参数，不改变对白内容。
- 已有分镜模式优先识别镜头号、场次、景别、机位、运镜、时长、画面、对白/旁白、角色、场景和道具；缺失字段可补全，但覆盖用户字段必须先显示差异并确认。
- 模式切换不删除当前文本；若文本结构与目标模式不匹配，只提示风险并提供“保留原文切换”与“取消”。
- 建议单集输入不超过 8000 字符；底部实时显示字符数、行数、自动保存状态。
- AI 续写、全文改写、选段改写、撤回改写必须产生版本记录，不能静默覆盖原文。
- 生成按钮在配置栏底部固定；点击后先校验正文、模型、画幅、时长与工作流，再创建可恢复后台任务。
- 右下角保留“漫剧 Agent”入口，用于解释当前页、定位缺失项和发起受控操作；Agent 不得绕过确认直接生成整集。

### 6.5 AI 分析结果：拍摄清单

参考：[BigBanana GitHub 拍摄清单截图](./assets/reference-bigbanana-shot-list-after-ai.png)。建议路由：`/v2/drama/projects/:projectId/episodes/:episodeId/manifest`。

点击“生成分镜脚本”后先创建可恢复的后台任务；任务成功即进入“拍摄清单 / SCRIPT MANIFEST”。拍摄清单是 AI 分析后的正式、可编辑生产数据，不是只读报告，也不是镜头图片生成页。

页面由四个稳定区域组成：

1. 全局导航栏：当前项目，以及剧本策划、视觉设定、镜头设计、剪辑交付和提示词库。
2. 顶部摘要栏：拍摄清单标题、项目名、总时长和保存状态；保存状态分为保存中、已保存、保存失败。
3. 分析摘要栏： 。演员条目包含姓名、性别和 AI 提取的身份、外貌、发型、服装、姿态、表情及技术风格描述。
4. 主清单：按场次分组，再按镜头纵向排列。

每个场次标题必须显示序号、地点/空间、子位置，以及时间、节奏或情绪，例如“01 林不凡家卧室（床边）”“早上约 8:30｜慵懒、滑稽、信息轰炸式的错愕”。

每个镜头采用三列结构：

- 左列：`SHOT 001` 和景别/运镜标签，例如 `WIDE SHOT`、`DOLLY SHOT`、`CLOSE-UP`、`OVER THE SHOULDER SHOT`。
- 中列：镜头叙事正文、动作、对白/内心独白，以及角色素材引用标签。
- 右列：可编辑的画面提示词；提示词按视觉风格、镜头运动、构图引导、起始帧要求和角色一致性约束分段，不显示为一个不可读的长字符串。

交互规则：

- 故事梗概、演员资料、场次和镜头字段均可编辑；修改后立即标记当前 Manifest 版本为未保存。
- 角色标签点击后打开角色详情或跳转到项目素材中的对应角色；不存在的引用显示“待创建素材”。
- 画面提示词提供独立编辑入口，并区分 AI 原始值、用户修改值和当前生效值。
- 用户可返回剧本重新生成，但必须创建新的 Manifest 版本，旧清单保持可恢复。
- 只有拍摄清单完成必要字段校验后，才能进入视觉设定或镜头设计；缺失项以镜头级错误显示。

## 7. 页面四：角色与场景

路由：`/v2/drama/projects/:projectId/episodes/:episodeId/assets`

拍摄清单确认后，系统把 Manifest 中的角色、场景和道具引用转换为项目级草稿实体，并进入“角色与场景 / ASSETS & CASTING”。参考：[BigBanana 角色与场景截图](./assets/reference-bigbanana-characters-scenes.png)。这里确认的是跨镜头一致性素材，不是单镜头画面。

### 7.1 页面布局与工具栏

- 左侧延续当前项目与阶段导航，“角色与场景/视觉设定”为当前阶段。
- 顶部显示页面标题；右侧依次为“素材库”、图片模型/生成类型、横屏/竖屏、当前条目数量和保存状态。
- comfyui-console 适配版不建立独立资产库：截图中的“资产库”统一替换为现有“素材库”，图片模型选择器来自生成类型与 ComfyUI 工作流绑定。
- 主区默认使用三列大卡网格；角色卡完整展开提示词与操作，避免必须进入详情页后才能审核 AI 提取结果。
- 角色、场景、道具使用页内分组或筛选切换；第一屏优先展示拍摄清单中被引用的角色。

### 7.2 角色卡

每张角色卡包含：

- 主形象预览、右上角选择框、名称、性别、年龄/身份和服装变体数量。
- 服装变体入口；变体必须属于当前角色，并能被镜头单独引用。
- `重新生成`、`上传`、`从素材库替换`；三者都创建新版本，不直接破坏当前已采用图片。
- 可编辑的“角色提示词”长文本区，保留 AI 分析出的身份、面部、发型、服装、姿态表情和技术质量分段。
- 黑色主按钮“重新生成图片”、次按钮“保存到素材库”、危险按钮“删除角色”。
- 条目保存状态与引用状态；已被镜头使用的角色删除前必须列出受影响镜头。

批量选择用于统一生成、统一切换工作流或统一保存到素材库，不表示角色已经审核通过。审核状态单独显示“待确认/已确认/需修改”。

### 7.3 角色详情抽屉

抽屉标签：

1. 基础档案：姓名、别名、年龄感、身份、性格、外观和反向约束。
2. 参考素材：主图、多参考图、来源和使用次数。
3. 角色衣橱：造型列表、当前造型、生成/上传、历史版本。

### 7.4 服装变体弹窗

参考：[服装变体弹窗](./assets/reference-character-wardrobe-variations-modal.png)。点击角色卡“服装变体”打开大尺寸模态框，标题区显示角色头像、姓名和 `WARDROBE & VARIATIONS`，关闭按钮位于右上角。

弹窗分为左右两栏：

- 左栏 `BASE APPEARANCE`：展示基础造型大图并标记 `DEFAULT`，下方显示角色基础提示词。基础造型只负责身份、面部、体型等稳定特征，不被服装描述覆盖。
- 右栏 `VARIATIONS / OUTFITS`：上方列出已有服装变体，每项包含缩略图、变体名称、服装说明、重新生成、上传和删除；下方提供“变体名称”“服装/状态视觉描述”和“添加变体”。

服装生成规则：

- 新增变体必须填写名称和视觉描述；名称在同一角色内唯一，例如“格子衫”“战术装备”“晚宴礼服”。
- 生成时固定引用角色基础造型与身份约束，只允许服装、配饰、妆发和剧情状态发生变化；默认使用当前角色图片工作流。
- `重新生成`、`上传`均创建服装变体的新图片版本；完成后用户选择采用版本。
- 变体可单独保存到素材库，但仍通过 `character_id` 归属于角色，不创建重复角色。
- 被镜头引用的服装变体不能直接删除；先显示引用镜头，并要求替换为基础造型或其他变体。
- 关闭弹窗不会取消后台生成任务，列表持续显示排队、生成中、失败和已就绪状态。

### 7.5 造型九宫格

点击“生成造型九宫格”打开专用面板：造型主题、服装、发型、妆容、配饰、场合、参考图和负面约束。生成后显示完整九宫格及 9 个可裁切单元；可将整图保存为参考，也可选择单格创建 CharacterVariant。

### 7.6 场景与道具

场景和道具使用同一个 `ProjectAssetCard` 组件，仅通过实体类型扩展字段。参考图分别见文首“项目素材卡参考”。

共享卡片骨架从上到下为：

1. 媒体区：未生成时显示类型图标、`生成` 和 `上传`；已有图片时显示大图、右上角采用/选择标记，并允许打开预览。
2. 标题区：名称、摘要和实体特有标签。
3. 提示词区：标题为“场景提示词”或“道具提示词”，右侧编辑按钮；正文为可滚动文本区。
4. 媒体操作区：已有图片时显示“重新生成”“上传图片”；未生成时操作保留在媒体区，避免重复按钮。
5. 素材操作区：统一显示“保存到素材库”；若已保存则显示素材库状态和“从素材库替换”。
6. 危险操作区：底部红色描边“删除场景/删除道具”。

道具卡特有字段：

- 道具分类下拉，例如其他、武器、服饰、交通工具、文书、装置。
- 简短描述、归属角色、出现范围和连续性说明。
- 未设置提示词时显示明确警告：“未设置提示词，点击编辑按钮添加视觉描述。”；此时允许上传，但生成按钮需要先引导补充提示词或由 AI 补全候选。

场景卡特有字段：

- 场景名称、子位置、时间标签，例如“林不凡家卧室（床边）”“早上约 8:30”。
- 节奏/氛围摘要，例如“慵懒、滑稽、信息轰炸式的错愕”。
- 场景提示词包含空间结构、固定物、陈设、材质、光线、天气、色板、镜头可用方向和技术质量；不能只描述一张构图。
- 场景图片是跨镜头概念素材；卡片被勾选表示当前采用版本，不表示所有引用镜头已重新生成。

共享状态：未配置、待生成、排队中、生成中、待确认、已采用、生成失败、依赖过期。重新生成、上传或素材库替换都创建新版本，确认采用后再更新当前实体引用。

组件最小输入契约：`entityType`、`name`、`summary`、`metadataTags`、`prompt`、`currentResource`、`currentVersion`、`status`、`selected`、`libraryResourceId`、`referenceCount`；场景和道具只通过 `metadata` 插槽扩展字段，不能复制整套卡片代码。

### 7.7 阶段确认门禁

- 页面顶部持续显示“待确认角色/场景/道具”数量。
- 进入镜头设计前，所有被拍摄清单引用的角色和场景必须至少存在一个已采用素材版本；非关键道具可标记为后补。
- 图片生成使用 comfyui-console 任务队列，卡片展示排队、生成中、成功、失败和重试状态；离开页面不会中断任务。
- 确认后将对应 Manifest 引用锁定到具体素材版本；以后更换素材时显示受影响镜头并触发过期依赖提示。

## 8. 页面五：导演工作台

路由：`/v2/drama/projects/:projectId/episodes/:episodeId/director`

这是漫剧模块的核心页面，也是唯一导演入口。

### 8.1 页面布局

```text
工具栏：场次筛选 | 全部/未完成/已完成 | 批量操作 | 全自动生成

场次分组标题：1-3 夜 内景 · 地下仓库      环境状态
┌────────────┐ ┌────────────┐ ┌────────────┐
│ 镜头 01    │ │ 镜头 02    │ │ 镜头 03    │
│ 预览/状态  │ │ 预览/状态  │ │ 预览/状态  │
│ 画面描述   │ │ 画面描述   │ │ 画面描述   │
│ 6s · 推镜  │ │ 4s · 固定  │ │ 3s · 特写  │
└────────────┘ └────────────┘ └────────────┘

选中镜头后右侧打开详情抽屉
```

镜头卡预览优先级：已采用视频封面 > 已采用关键帧 > 宫格图 > 空占位。左上角复选框；右上角状态；底部显示镜头号、时长、运镜和角色小头像。

卡片状态：缺少环境、待审描述、待生成图片、图片就绪、视频生成中、视频就绪、已采用、失败。颜色只作为辅助，必须显示文字或图标。

### 8.2 顶部操作

- 场次筛选、状态筛选、卡片/紧凑视图。
- 新建镜头、智能拆镜。
- 批量设置输入模式、批量选择工作流、批量生成。
- 全自动模式：打开执行计划，不直接运行。

### 8.3 镜头详情抽屉

抽屉从上到下：

1. 镜头标题、状态、上一镜/下一镜、保存状态。
2. 镜头属性：画面描述、动作、表情、对白、情绪、景别、机位、运镜、构图、时长。
3. 场景环境：场景、时间天气、角色造型、道具；缺失项直接进入对应编辑器。
4. 宫格/关键帧区。
5. 视频生成区。
6. 配音区。
7. 运行记录与历史版本。

详情抽屉内的长区块使用折叠面板，但当前阻断区块自动展开。

### 8.4 镜头角色服装选择

参考：[镜头角色服装选择器](./assets/reference-shot-character-outfit-selector.png)。镜头详情的“场景环境 / SCENE CONTEXT”先显示场景卡，再逐行显示本镜头角色。每一行包含角色头像、姓名、移除按钮和服装下拉框。

下拉选项至少包含：

- `基础造型`：继承角色当前基础外观。
- `服装 · {变体名}`：列出该角色所有已采用且资源可用的服装变体，例如“服装 · 格子衫”。

选择规则：

- 选择结果保存为当前镜头的角色造型绑定；默认从上一镜、场次默认值或角色基础造型继承，并显示继承来源。
- 单镜头切换服装只影响该镜头。需要跨场次或批量应用时使用明确的“应用到本场次/后续镜头”操作并预览影响数量。
- 切换后重新编译该镜头的角色一致性提示词，并将已生成关键帧、宫格和视频标记为“依赖已过期”；不自动删除历史结果。
- 下拉只显示已就绪服装；生成中和失败项显示状态但不可采用。
- “添加角色到此镜头”后同样必须选择基础造型或服装变体，才能通过视觉生成前检查。

## 9. 宫格分镜面板

### 9.1 创建流程

```text
选择 4/6/9 格 → AI 生成逐格描述 → 人工编辑确认 → 生成宫格图
→ 使用整图 / 裁切单格 → 设为当前版本
```

格数使用分段按钮。描述编辑器按真实网格排列，每格显示编号、景别、动作和描述。用户必须能够只重写某一格、拖动换序和复制上一格描述。

### 9.2 结果区

- 主预览保持原始宫格比例。
- 右侧版本列表显示 V1/V2、创建时间、来源工作流和采用状态。

## 10. 视频生成面板

### 10.1 输入模式

模式标签仅显示当前工作流支持的能力：

- 首帧/参考图
- 首尾帧
- 网格分镜
- 多参考图
- 参考视频

切换模式时保留各模式草稿，但提交只带当前模式素材。素材槽显示用途名称，不显示泛化的 `input_image_1`。

### 10.2 参数区

顶部先显示模型能力卡：业务名称、工作流版本、支持输入、时长、比例和当前节点状态。随后显示提示词、负面提示词、比例、时长、分辨率、种子及工作流公开参数。

主按钮状态：

- `生成视频`：可提交。
- `缺少首帧`：禁用并可点击定位。
- `工作流不支持尾帧`：禁用，提供更换工作流。
- `排队中/生成 46%`：展示进度和取消。
- `重新生成`：当前已有结果时创建新 Take。

### 10.3 结果和版本

当前视频使用 16:9 或项目比例播放器；下方 VersionStrip 显示 Take。操作包括采用、对比、下载、评价、返工和删除非采用版本。切换历史版本只改变当前采用关系，不修改 Resource。

## 11. 配音面板

页面支持旁白和对白两类 cue。每行显示说话人、文本、目标时长、音色、情绪、语速、当前音频和状态。

- 角色默认音色在项目级绑定，镜头内可临时覆盖。
- 从剧本同步时保留人工修改过的 cue，并显示文本差异。
- 单句生成、批量生成、试听、采用、替换和重新生成。
- 生成类型与工作流选择通过“语音能力槽位”解析，普通用户只看到音色和公开参数。

## 12. 成片、剪辑与导出

路由：`/v2/drama/projects/:projectId/episodes/:episodeId/delivery`

### 12.1 成片总览

顶部显示镜头完成度、已采用视频数、配音完成度、预计时长和阻断项。中部按镜头顺序展示可播放列表；缺少视频或音频的镜头有清晰占位。

## 13. 提示词库

路由：`/v2/drama/projects/:projectId/prompts`

页面按参考截图采用“统计分类卡 + 搜索筛选 + 可展开条目”结构：

编辑弹窗提供中文/English、变量插入、未知变量校验、编译预览和“另存为通用提示词”。恢复默认只删除项目覆盖，不改系统模板。

## 14. 模型与工作流绑定

入口：项目库“设置”或项目设置“模型绑定”。页面只管理业务能力槽位：角色图、场景图、道具图、宫格图、关键帧、首帧视频、首尾帧视频、多参考视频、TTS。

每行包含：

- 能力名称和所需输入。
- 已绑定 GenerationType/WorkflowVersion。
- 能力标签和兼容状态。
- 默认参数摘要。
- 更换、测试编译、恢复平台默认。

选择工作流时只列出已发布且媒体类型匹配的版本。不兼容项仍可查看，但不能保存为启用绑定；详情列出缺少的语义槽位和输出映射。

## 15. 全自动模式

全自动入口位于剧本页和导演工作台。点击后先打开执行计划弹窗：

1. 范围：当前镜头、所选镜头、当前场次、当前集。
2. 计划：补角色/场景资产、生成描述、宫格/关键帧、视频、配音。
3. 逐镜头策略：输入模式、宫格数、工作流、跳过条件。
4. 检查结果：会执行、会跳过、被阻断和预计任务数。

开始后使用可恢复 AutomationRun。任务抽屉显示阶段树、当前进度、失败原因、暂停、继续、跳过和重试。任何 `edited_by_user=true` 的内容默认锁定，必须由用户主动允许覆盖。

## 16. 状态与异常设计

每个核心页面必须包含：

- 首次空状态：说明下一步且只有一个主动作。
- 加载骨架：结构与最终内容一致。
- 局部失败：失败区块单独重试，不清空其他内容。
- 无权限/工作流停用：显示原因和可去的设置入口。
- 后台任务：离开页面继续，返回后恢复进度。
- 冲突：显示本地/远端版本时间，允许对比后选择。
- 被引用资源删除：阻止永久删除并列出使用位置。

## 17. 首轮开发边界

首轮先落地以下页面骨架和组件，不立即实现完整时间线：

1. `DramaProjectShell` 和项目侧栏。
2. 项目库、新建项目、项目总览。
3. 剧本与故事三栏页。
4. 角色/场景/道具卡片页及详情抽屉。
5. 导演工作台、镜头卡、镜头详情抽屉。
6. 宫格分镜和视频生成面板。
7. 项目提示词库。
8. 模型能力绑定页。

成片页第一版提供顺序预览、基础合并和导出入口；多轨 AI 剪辑在上述生产闭环稳定后实现。

## 18. 实站界面对照结论

取证页面：`https://director.tree456.com/workspace`，复核日期为 2026-08-28。

### 18.1 已确认的视觉参数

- 页面背景实际为约 `rgb(247,245,240)`，即 `#F7F5F0`。
- 正文主色约 `#44413D`，大标题约 `#1A1816`。
- 字体以 Inter/系统无衬线为主；核心标题多用 300 轻字重，不使用粗重 SaaS 标题。
- 内容区居中、最大宽度约 1180–1240 px；项目库没有左侧平台导航。
- 容器以细暖灰边框、20–24 px 大圆角和极弱阴影为主。
- 页面背景存在非常轻的等高线/拓扑线装饰，但不影响信息阅读。
- 主按钮使用纯黑底白字；次按钮白底细边框；统计使用小型胶囊。

### 18.2 项目库真实层级

1. 顶部标题、英文副标题、说明文案和紧凑统计胶囊。
2. 顶部右侧语言、返回首页、新建项目、帮助、设置和主题。
3. 首屏左侧“继续最近项目”，右侧“快速查找项目”。
4. 最近项目大卡强调更新时间、角色/场景/道具和继续编辑。
5. 第二屏才进入“全部项目”。

因此原先“全局左侧栏 + KPI 卡 + 封面网格”的方案废弃。`comfyui-console` 集成通过“返回首页”回到平台，不在项目库强行叠加平台侧栏。

### 18.3 新建项目真实行为

- “新建项目”是立即创建动作，不打开前置配置表单。
- 系统自动创建默认项目和“第 1 集”，随后进入项目总览。
- 项目总览先引导用户进入剧本策划与分镜，再按需补角色、场景、道具和世界观。
- “导入整篇小说”“导出整项目”位于项目主卡底部。
- 资源工作台和剧集管理位于首屏之后。

因此原先“三步新建项目表单”废弃。语言、比例、时长、风格和工作流绑定放到项目设置/剧本策划中，不阻塞项目创建。

### 18.4 复刻时不纳入的实站元素

- 账号中心、服务协议、会员、积分、付费和商业授权。
- 加群、外部资源共创平台和自媒体平台推广。
- 对方品牌名、站点名称、Logo、专有插图和水印。

保留的是布局、交互优先级和信息组织方式，不复制其品牌资产与运营入口。

### 18.5 第 1 集剧本策划实站结构

取证路由：`/project/:projectId/episode/:episodeId`；参考图见文首“第 1 集剧本策划”。

- 左侧全局栏固定项目与集数上下文，并将流程压缩成“剧本策划—视觉设定—镜头设计—剪辑交付—提示词库”。
- 主区先是独立滚动的项目配置栏，再是占据最大面积的剧本编辑器，不再设置场次目录栏。
- 配置栏底部固定“生成分镜脚本”；编辑器顶部固定 AI 续写、AI 改写、选段改写、撤回改写和自定义要求。
- 空白项目默认采用小说生成分镜、中文、横屏和 60 秒规划，并明确显示按当前视频模型单镜时长估算的镜头数量。
- 文本编辑器显示 8000 字符建议、字符数、行数和自动保存状态；选段改写在没有选区时禁用。
- 分镜模型来自平台模型配置；在 comfyui-console 中必须进一步绑定模型能力与 ComfyUI 工作流，避免只记录一个展示名称。

此结论替代第 6 节旧版三栏设想；初始剧本输入完成后先进入“拍摄清单”审核 AI 分析结果，审核通过后才进入视觉设定与镜头设计。

# V1 基线验收记录（2026-08-12）

## 验收范围

- V2 功能开关默认关闭时，V1 仍为默认入口。
- V1 原有路由、接口和业务组件未迁移。
- V2 仅新增独立目录、路由骨架、预览占位页和双向切换入口。
- 本轮未修改数据库模型、迁移文件或 `/api/v1` 接口。

Windows/PowerShell 后端完整基线命令：

```powershell
$env:PYTHONPATH='backend'
python -c "from fastapi.testclient import TestClient; from app.main import app; c=TestClient(app); c.__enter__(); c.__exit__(None,None,None)"
pytest -q
```

说明：核心接口测试使用模块级 `TestClient`，单独运行 `pytest` 不会自动进入应用 lifespan。首次在空工作区运行时，应先用上述初始化命令创建 SQLite 表和种子数据。

## 功能开关验证

- 未配置 `VITE_UI_V2_ENABLED`：等同于 `false`，V1 不显示 V2 入口，直接访问 `/v2` 会回到 V1 首页。
- 配置为 `true`：登录后可从 V1 进入 `/v2`，也可从 V2 返回稳定版。
- 支持的真值：`1`、`true`、`yes`、`on`，大小写不敏感。

## 本轮结论

Iteration 0 的 V2 隔离骨架满足开工验收条件。V1 仍是默认稳定版本，V2 后续页面可在 `frontend/src/v2` 内独立演进。

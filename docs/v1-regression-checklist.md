# ComfyUI Console V1 稳定版回归清单

> 用途：V2 每次合并和发布前验证 V1 未被破坏。
> 原则：V2 默认关闭；关闭后 V1 的路由、界面、接口和任务执行行为必须与当前稳定版一致。
## 1. 自动化门禁

```bash
cd backend
pytest -q

cd ../frontend
npm run typecheck
npm run build
```

- [ ] 后端测试全部通过。
- [ ] 前端类型检查通过。
- [ ] 前端生产构建通过。
- [ ] 构建输出没有新增阻断级警告。

## 2. 登录与全局框架

- [ ] 未登录访问 `/` 自动进入 `/login`。
- [ ] 正确账号可以登录并进入 V1 首页。
- [ ] 退出登录后 Token 清除并返回登录页。
- [ ] V2 开关关闭时不显示“体验 V2”入口。
- [ ] V2 开关关闭时访问 `/v2` 自动返回 V1 首页。
- [ ] 桌面侧栏和移动端底部导航可正常使用。

## 3. 系统概览

- [ ] 今日任务、状态统计、素材统计可以加载。
- [ ] 最近任务和节点状态可以显示。
- [ ] Dashboard 接口失败时页面给出错误提示且不崩溃。

## 4. 生成页面

每次至少回归文生图、图生视频和动作迁移。

- [ ] 生成类型动态菜单正确显示。
- [ ] 每个生成页面只显示本类型工作流。
- [ ] 工作流默认值和尺寸默认值正确。
- [ ] 图片、视频、音频输入支持本地上传。
- [ ] 图片、视频、音频输入支持从素材库选择。
- [ ] 输入素材选择后显示正确预览。
- [ ] 文生图逐行生成和批量生成可提交。
- [ ] 图生视频选择的图片、时长和提示词传入工作流。
- [ ] 动作迁移不显示和不提交提示词。
- [ ] 动作迁移参数方案、跳过秒数和多参输入正确。
- [ ] 提示词文本文件按一行一条导入，其他参数使用页面默认值。
- [ ] 生成结果支持多个图片、视频或音频文件。
- [ ] 图片可放大，视频可播放，音频可试听。

## 5. 工作流管理

- [ ] 工作流列表限定当前生成类型。
- [ ] 上传 API JSON 后能自动识别节点和参数。
- [ ] 选择组件节点后根据该节点 `inputs` 自动匹配。
- [ ] 参数名称下拉来自所选节点的 `inputs` 属性。
- [ ] 数字、开关、小数可匹配 `value`、`Float` 或 `text`。
- [ ] 图片、视频、音频分别匹配对应多媒体属性。
- [ ] 可以修改工作流名称和重新上传 JSON。
- [ ] 可以增加工作流版本并设置默认工作流。

## 6. 任务管理

- [ ] 默认显示当天任务。
- [ ] 日期、状态、生成类型和关键词筛选有效。
- [ ] 生成类型和任务状态显示文字。
- [ ] 任务行显示图片或视频首帧预览。
- [ ] 任务详情显示参数、运行事件、错误和执行结果。
- [ ] 任务详情多媒体参数只读并显示预览。
- [ ] 普通参数修改后执行会创建新任务，原任务不变。
- [ ] 后端阻止通过接口修改原任务多媒体参数。
- [ ] 草稿可以删除。
- [ ] 完成或失败任务可以重新生成。
- [ ] 图片查看器支持缩放、拖动和复位。

## 7. 素材库

- [ ] 目录树可以展开和折叠。
- [ ] 默认定位当天任务结果目录。
- [ ] 新结果归档到“任务结果/月份/日期/任务ID+任务类型”。
- [ ] 不自动创建图片、视频分类目录。
- [ ] 用户可创建无限级普通目录。
- [ ] 图片、视频、音频可迁移到目录。
- [ ] 图片缩略图完整显示。
- [ ] 视频显示首帧并可放大播放。
- [ ] 音频可以播放。
- [ ] 任务生成素材可以查看生成参数。

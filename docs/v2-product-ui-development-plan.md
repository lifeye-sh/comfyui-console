# ComfyUI Console V2 产品、界面详细设计与开发计划

> 文档状态：设计基线（待评审）  
> 文档版本：V2.0-DRAFT  
> 编写日期：2026-08-12  
> 适用范围：新一代菜单、Glassmorphism 界面、生成类型配置中心及响应式移动端  
> 重要约束：现有版本继续作为稳定版运行，V2 不得破坏、替换或改变现有版本功能。

---

## 1. 文档目标

本文档用于指导 ComfyUI Console 新版本的产品设计、交互设计、前后端开发、测试、灰度发布和最终验收。V2 的核心目标是：

1. 在保留当前全部业务能力的基础上，建立清晰、可扩展的新信息架构。
2. 使用克制的 Glassmorphism 视觉语言重构桌面端和移动端体验。
3. 将生成页面升级为由“生成类型配置”驱动的统一页面系统。
4. 统一任务、素材、工作流和生成类型之间的关系。
5. 通过版本隔离和功能开关，保证现有稳定版始终可用、可回退。

本文档不授权直接删除、迁移或改写稳定版功能。任何 V2 实施工作都必须遵守第 2 章的版本隔离要求。

## 2. 版本策略与稳定版保护

### 2.1 版本定义

| 名称 | 定义 | 状态 |
| --- | --- | --- |
| Stable/V1 | 当前已经运行的菜单、页面、接口和数据行为 | 保持不变，持续可用 |
| Next/V2 | 本文档定义的新菜单、新界面和配置能力 | 独立开发、分阶段启用 |

### 2.2 不变性红线

V2 开发期间必须保证：

- 不删除 V1 页面、路由、接口或数据字段。
- 不改变 V1 接口已有字段的含义、类型和默认行为。
- 不改变现有任务调度、ComfyUI 提交、输入素材上传和输出回收逻辑。
- 不改变历史任务、历史素材和历史工作流的可访问性。
- 不强制迁移现有用户到 V2。
- 不使用破坏性数据库迁移；新增字段必须可空或有安全默认值。
- V2 出现故障时，用户必须能够立即返回 V1。

### 2.3 推荐隔离方式

前端采用并行入口：

```text
/                 -> 根据功能开关进入稳定版或新版本
/v1/*             -> 当前稳定版路由，长期保留
/v2/*             -> 新版路由
```

实现阶段若不适合立即迁移 V1 路由，可先保持当前路由不变，仅新增 `/v2` 路由树。V2 验收完成后，再通过入口开关调整默认版本。

后端优先复用兼容接口；确实需要不同响应结构时采用以下方式之一：

- 新增不破坏旧字段的扩展接口。
- 新增 `/api/v2`，不得直接改变 `/api/v1` 的既有行为。
- 使用明确的查询参数请求扩展信息，例如 `include=events,outputs`。

### 2.4 功能开关

至少提供以下开关：

| 开关 | 说明 |
| --- | --- |
| `ui_v2_enabled` | 是否允许访问 V2 |
| `ui_v2_default` | 登录后是否默认进入 V2 |
| `generation_type_designer_enabled` | 是否开放生成类型编辑器 |
| `generation_type_publish_enabled` | 是否允许发布配置 |
| `mobile_v2_enabled` | 是否启用新版移动端布局 |

### 2.5 回退策略

- 页面级回退：V2 顶部用户菜单提供“返回稳定版”。
- 发布级回退：关闭 `ui_v2_default` 即恢复 V1 默认入口。
- 配置级回退：生成类型发布形成不可变版本，可回滚到上一次已发布版本。
- 数据库回退：V2 迁移仅新增表或字段，不依赖删除字段完成回滚。

## 3. V2 产品范围

### 3.1 本期包含

- 新版全局框架和完整菜单。
- 系统概览 Dashboard。
- 图片、视频、音频统一生成页面框架。
- 任务管理、任务详情和批次任务入口。
- 素材库、目录树和多媒体预览。
- 生成类型配置中心。
- 类型专属工作流管理入口。
- 参数方案、尺寸和选项配置的统一入口。

- Glassmorphism 设计系统。
- V1/V2 切换、灰度与回退机制。

- 自由拖拽式页面搭建器。
- ComfyUI 节点画布在线编辑。

- 多租户计费体系。
- 原生 iOS/Android 应用。
- 对历史任务参数和历史工作流版本的批量重写。

## 4. 用户角色与权限

### 4.1 普通用户

- 使用已发布的生成类型。
- 创建、提交、取消和重新生成自己的任务。
- 查看自己的任务详情、参数和结果。
- 管理有权限的素材与目录。
- 使用提示词库和已授权工作流。

### 4.2 管理员

拥有普通用户能力，并可：

- 管理 ComfyUI 节点。
- 新建、编辑、检查、测试、发布和停用生成类型。
- 管理参数方案与选项配置。
- 管理类型专属工作流和参数映射。
- 查看审计日志和回收站。

### 4.3 权限原则

- 主菜单按权限裁剪，禁止仅通过前端隐藏代替后端鉴权。
- 普通用户不显示“系统配置”。
- 工作流管理权限仍按生成类型和所有者进行约束。
- 配置发布、默认工作流变更、永久删除必须记录审计日志。

## 5. 新版信息架构与菜单

### 5.1 Web 侧边菜单

```text
系统概览

AI 生成
├─ 图片生成
│  ├─ 文生图
│  ├─ 图生图
│  └─ 后台已发布的图片类型
├─ 视频生成
│  ├─ 文生视频
│  ├─ 图生视频
│  ├─ 动作迁移
│  ├─ 人物替换
│  └─ 后台已发布的视频类型
└─ 音频生成
   ├─ 文生音频
   ├─ 音频处理
   └─ 后台已发布的音频类型

任务中心
├─ 任务管理
└─ 批次任务

素材中心
├─ 素材库
├─ 参考视频
└─ 提示词库

系统配置（管理员）
├─ 节点管理
├─ 生成类型配置
├─ 参数方案
├─ 选项配置
├─ 审计日志
└─ 回收站
```

### 5.2 菜单规则

- 生成类型由后端动态返回，按 `media_type` 分组、按 `menu_order` 排序。
- “动作迁移”和“人物替换”直接作为视频生成子项，不设置“迁移替换”中间层。
- 工作流管理不作为主菜单；从具体生成页面右上角进入。
- 侧边栏支持折叠，折叠后保留图标和 Tooltip。
- 同一时间只突出一个活动菜单；父级自动展开。
- 菜单状态和用户最后展开状态可本地保存。

### 5.3 移动端导航

底部固定五项：

```text
概览 | 生成 | 任务 | 素材 | 我的
```

- “生成”打开全屏或大尺寸底部抽屉，显示最近使用、收藏及三类生成菜单。
- “我的”显示个人信息；管理员额外显示系统配置入口。
- 二级页面使用顶部返回按钮和标题，不保留桌面侧边栏。

## 6. Glassmorphism 设计系统

### 6.1 视觉原则

玻璃效果服务于层级，不牺牲可读性。表格、长表单和正文区域必须使用较高不透明度，背景光斑不得穿透影响文字。

### 6.2 设计令牌建议

```css
--v2-bg-0: #07111f;
--v2-bg-1: #0b1730;
--v2-surface: rgba(21, 39, 72, 0.72);
--v2-surface-strong: rgba(22, 39, 69, 0.90);
--v2-surface-soft: rgba(255, 255, 255, 0.06);
--v2-border: rgba(255, 255, 255, 0.16);
--v2-border-hover: rgba(151, 181, 255, 0.45);
--v2-text: #f5f8ff;
--v2-text-secondary: #aebbd2;
--v2-primary: #6475f6;
--v2-primary-end: #8b5cf6;
--v2-success: #40c98b;
--v2-warning: #e5b85c;
--v2-danger: #ef6b78;
--v2-radius-card: 18px;
--v2-radius-control: 10px;
--v2-blur: 18px;
--v2-shadow: 0 18px 45px rgba(0, 0, 0, 0.28);
```

### 6.3 玻璃层级

| 层级 | 用途 | 推荐不透明度 |
| --- | --- | --- |
| G0 | 页面背景和光斑 | 不使用内容玻璃 |
| G1 | 侧栏、顶栏、普通卡片 | 0.65–0.75 |
| G2 | 表格、配置表单、详情正文 | 0.85–0.92 |
| G3 | 弹窗、抽屉、危险确认 | 0.94 以上 |

### 6.4 组件规范

- 卡片：18px 圆角、1px 半透明白边、柔和悬浮阴影。
- 按钮：主要按钮使用蓝紫渐变；次要按钮为透明描边；危险按钮只在危险操作使用红色。
- 输入框：10px 圆角，默认背景 `rgba(255,255,255,.055)`，聚焦显示蓝紫外圈。
- 标签：状态色面积小且文字明确，不能只依赖颜色表达状态。
- 表格：行高不低于 48px；操作列固定；横向滚动仅用于桌面窄窗口。
- 弹窗：关键编辑使用居中弹窗，复杂详情使用右侧抽屉。
- 空状态：说明原因并提供一个明确下一步操作。

### 6.5 动效

- 页面和抽屉过渡 160–220ms。
- Hover 位移不超过 2px。
- 遵循 `prefers-reduced-motion`。
- 禁止持续闪烁、强烈霓虹和影响 GPU 的大面积动态模糊。

### 6.6 可访问性

- 正文对比度达到 WCAG AA。
- 键盘可访问所有按钮、列表、菜单和弹窗。
- 焦点状态清晰可见。
- 图标按钮必须提供文本标签或 `aria-label`。
- 点击目标桌面不小于 36px，移动端不小于 44px。

## 7. 全局应用框架

### 7.1 Web 框架

- 左侧：可折叠动态菜单。
- 顶部：面包屑、全局搜索、节点状态、通知、用户菜单。
- 主体：最大宽度自适应，允许业务表格使用全宽。
- 右侧：任务详情、素材详情等上下文抽屉。

### 7.2 全局搜索

首期搜索范围：

- 任务 ID、批次 ID、提示词。
- 素材文件名。
- 工作流名称。
- 生成类型名称。

搜索结果按类型分组，点击进入具体页面。

### 7.3 页面状态

每个页面必须统一处理：

- 首次加载骨架屏。
- 空数据。
- 局部加载。
- 接口失败与重试。
- 无权限。
- V2 功能未开启。

## 8. 主要页面详细设计

### 8.1 系统概览

#### 页面目标

让用户快速了解今日生产状态，并能进入常用生成类型或异常任务。

#### Web 布局

1. 指标区：今日任务、运行中、成功率、素材数量。
2. 趋势区：近 7 天任务数与成功任务数。
3. 分布区：按图片、视频、音频和具体生成类型统计。
4. 节点区：节点在线状态、GPU、显存、并发、在途任务。
5. 最近任务：预览、类型、状态、时间和详情入口。
6. 快捷入口：常用或收藏的生成类型。

#### 移动端

- 指标为两列卡片。
- 趋势图横向占满。
- 节点卡片横向滑动。
- 最近任务使用纵向卡片列表。

### 8.2 统一生成页面

#### 页面结构

```text
面包屑 + 类型标题                  工作流选择 / 管理工作流
全局设置（可折叠）
任务编辑区
结果预览区
批量操作区
```

#### 功能要求

- 根据生成类型发布版本加载参数定义。
- 工作流下拉仅显示当前生成类型的工作流。
- 全部多媒体参数支持上传和从素材库选择。
- 选中的图片显示缩略图；视频显示首帧并可播放；音频显示播放器。
- 桌面端批量模式可使用列表/表格；移动端每行转换为任务卡片。
- 支持添加、复制、删除、单行生成、批量生成、文件导入、保存批次。
- 已提交行不可直接修改，必须复制或重新生成。
- 工作流参数缺失时在提交前显示明确字段级错误。

#### 动作迁移特殊规则

- 参数设置只选择参数方案。
- 跳过秒数、多参开启、多参图数和多参图片保留为任务级参数。
- 原始视频和目标人物图为任务输入参数。

### 8.3 任务管理

#### 列表

- 默认查询当天任务。
- 查询条件：关键词、日期、状态、生成类型、批次、节点。
- 显示任务 ID、类型文字、状态文字、提示词摘要、预览、批次、节点、重试、时间和错误摘要。
- 草稿可删除；等待或执行中可取消；完成或失败可重新生成。

#### 任务详情

使用右侧抽屉，包含三个标签页：

1. 参数信息：参数快照、输入素材预览、工作流版本。
2. 运行信息：节点、Prompt ID、状态、重试、时间、耗时、事件时间线、错误。
3. 执行结果：全部图片、视频、音频结果及尺寸、时长、文件大小、目录和下载入口。

移动端使用全高底部抽屉或独立详情页。

### 8.4 批次任务

- 批次名称、来源、生成类型、总行数、成功/失败/运行数、整体进度。
- 查看批次行、重试失败行、取消未开始行、复制批次。
- 导入记录显示文件名、起始行列、成功数和无效数。

### 8.5 素材库

#### 目录规则

```text
任务结果
└─ YYYY-MM
   └─ YYYY-MM-DD
      └─ 任务ID + 任务类型
         └─ 任务结果文件
```

- 不再自动创建图片、视频目录。
- 用户可无限级创建普通目录。
- 目录支持折叠，默认定位当天任务结果。
- 素材可移动到有权限的目录。

#### 内容区

- 图片显示缩略图。
- 视频显示首帧和播放标识。
- 音频显示媒体图标、时长和播放器入口。
- 支持媒体类型、来源、日期、文件名筛选。
- 详情显示生成参数、来源任务和工作流版本。

#### 移动端

- 目录树改为抽屉和面包屑。
- 内容区两列卡片；小屏可切换单列。

### 8.6 工作流管理

- 从具体生成页面进入，并自动锁定生成类型。
- 只显示本类型工作流。
- 支持修改名称、上传新 JSON、添加版本、参数映射、输出映射、测试运行、设置默认和停用。
- 参数名称为下拉选择，选项来自所选 JSON 节点的 `inputs` 属性。
- 选择节点后自动匹配，数字、开关和小数按节点实际存在的 `value`、`Float`、`text` 选择。

## 9. 生成类型配置中心

### 9.1 列表页

显示：

| 字段 | 说明 |
| --- | --- |
| 类型名称 | 菜单和页面显示名称 |
| 类型编码 | 不可重复的稳定编码 |
| 媒体分类 | image/video/audio |
| 默认工作流 | 当前发布版本默认工作流 |
| 参数数 | 启用参数数量 |
| 排序 | 菜单顺序，支持拖动 |
| 状态 | 草稿/已发布/停用 |
| 更新时间 | 最后更新时间 |

操作包括新建、编辑、复制、预览、启用/停用。已经有历史任务的类型禁止物理删除。

### 9.2 编辑器结构

编辑器采用固定八步向导，不做自由拖拽画布：

1. 基础信息。
2. 页面配置。
3. 输入参数。
4. 参数联动。
5. 尺寸与视频设置。
6. 参数方案。
7. 工作流绑定。
8. 输出配置。

右侧提供 Web/移动端实时预览；底部固定“保存草稿、配置检查、测试运行、发布”。

### 9.3 基础信息

- 名称、编码、媒体分类、说明、图标、菜单排序、状态。
- 编码发布后锁定。
- 媒体分类决定菜单分组、结果预览和尺寸选项来源。

### 9.4 页面配置

- 页面模板：标准批量、单任务、复杂方案。
- 是否支持批量、导入、保存批次、提示词库。
- 是否显示全局提示词 1、全局提示词 2、负面提示词。
- 参数区域默认展开/折叠。

### 9.5 输入参数设计器

每个参数包含：

- 显示名称、参数编码、参数类型。
- 必填、启用、默认值、显示位置、排序。
- 占位文案、帮助说明、单位。
- 数字的最小值、最大值、步长。
- 下拉选项来源。
- 多媒体格式、大小、数量和素材库选择权限。

参数类型：单行文本、多行文本、整数、小数、种子、开关、下拉、图片、视频、音频。

参数可拖动排序，但不能任意拖到页面坐标；显示位置限定为全局设置、任务输入、更多参数。

### 9.6 参数联动

第一阶段支持：

- 等于、不等于。
- 数字大于等于、小于等于。
- 开关开启/关闭。
- 多条件“全部满足”。

支持的行为：显示、隐藏、启用、禁用、清空值。

### 9.7 尺寸与视频设置

- 图片默认尺寸：1088×1920。
- 视频默认尺寸：576×1024。
- 类型可从全局选项集勾选允许尺寸并重新排序。
- 视频可配置时长、帧率、帧数换算和限制。
- 默认值必须属于当前启用的选项。

### 9.8 参数方案

- 选择是否启用参数方案、方案分类和默认方案。
- 可配置任务行是否允许切换。
- 动作迁移复杂参数归入方案；跳过秒数、多参开关、多参图数和多参图片不归入方案。

### 9.9 工作流绑定

- 只能绑定当前生成类型的工作流。
- 显示版本、参数映射完整度、输出映射完整度、启用状态。
- 一个已发布类型只有一个默认工作流。
- 参数映射不完整的工作流不能设置为默认，除非缺失项均为可选。
- 可进入类型专属工作流管理和执行测试。

### 9.10 输出配置

- 主要输出类型和允许的附加类型。
- 是否允许多文件输出。
- 默认预览方式。
- 文件命名规则（受控模板）。
- 是否保存中间结果。
- 任务结果目录采用系统规则，不允许任意物理路径。

### 9.11 配置检查

发布前检查：

- 编码唯一且合法。
- 必须存在启用的默认工作流。
- 必填参数均有工作流映射。
- 多媒体参数类型一致。
- 默认尺寸和默认选项有效。
- 输出映射有效。
- 参数编码不重复。
- 参数联动不存在循环依赖。

错误阻止发布；警告可由管理员确认后发布并记录审计。

### 9.12 草稿、发布与版本

- 编辑始终作用于草稿。
- 发布生成不可变配置版本。
- 新任务使用最新发布版本；历史任务保留当时版本 ID 和参数快照。
- 支持查看版本差异、回滚到旧版本并重新发布。

## 12. 开发计划

以下计划以 2 名前端、1–2 名后端、1 名测试/产品协作为参考，可按实际人力调整。计划以阶段出口为准，不以日期强行发布。

### 阶段 0：基线冻结与保障（1 周）

工作内容：

- 建立 V1 核心回归清单和接口契约快照。
- 明确 V1/V2 路由和功能开关。
- 备份数据库并验证恢复流程。
- 为任务生成、输入素材、工作流映射和输出回收补关键自动化测试。

出口条件：

- V1 回归测试可重复执行。
- 关闭 V2 开关时系统行为与当前版本一致。

### 阶段 1：设计系统与新版框架（2 周）

工作内容：

- 建立 V2 token、GlassCard、按钮、表单、表格、弹窗、抽屉。
- 实现 Web 侧栏、顶栏、面包屑和移动端底部导航。
- 实现权限裁剪、动态生成菜单、V1/V2 切换。
- 建立响应式和可访问性基线。

出口条件：

- 所有菜单能正确路由。
- 桌面和移动端框架通过视觉及键盘访问验收。

### 阶段 2：核心业务页面迁移（3 周）

工作内容：

- 系统概览。
- 统一生成页面 V2 外壳，复用现有提交能力。
- 任务管理、任务详情和事件时间线。
- 素材库、目录、媒体预览和素材选择器。

出口条件：

- 文生图、图生视频、动作迁移至少各完成一次端到端生成。
- 图片、视频、音频输入和输出预览正常。
- 移动端完成创建任务、查看状态、播放结果闭环。

### 阶段 3：生成类型配置后端（2–3 周）

工作内容：

- 配置草稿和发布版本模型。
- 配置校验、版本、回滚、预览接口。
- 类型与工作流绑定完整度检查。
- 任务保存生成类型版本引用。
- 发布和回滚审计日志。

出口条件：

- 发布配置不会改变历史任务。
- 可回滚到任意已发布版本。
- 错误配置不能发布。

### 阶段 4：生成类型配置前端（3 周）

工作内容：

- 类型列表、筛选、排序、复制和停用。
- 八步编辑器。
- 参数设计器、联动、尺寸和参数方案。
- 工作流绑定、输出配置、配置检查。
- Web/移动端实时预览。

出口条件：

- 管理员无需修改代码即可创建一个测试生成类型。
- 发布后动态菜单和生成页面正确出现。
- 停用后不能新建任务，但历史任务仍可查看。

### 阶段 5：全量回归、性能和灰度（2 周）

工作内容：

- V1/V2 双版本功能回归。
- 浏览器和移动设备兼容性测试。
- 素材大目录、500 条任务、长事件时间线性能测试。
- 管理员小范围灰度、普通用户灰度。
- 收集体验数据并修正高频问题。

出口条件：

- 无阻断级缺陷。
- V1 不受影响且一键回退有效。
- 性能、可访问性和移动端验收通过。

### 阶段 6：正式发布与稳定观察（1 周以上）

- 初期保留 V1/V2 切换入口。
- 分批提高 V2 默认用户比例。
- 监控错误率、任务成功率、页面性能和接口延迟。
- V2 稳定后再单独评审是否调整 V1 维护策略；本项目计划不包含下线 V1。

## 13. 测试与验收

### 13.1 V1 保护性验收

- 原有菜单和路由可访问。
- 原有生成页面功能一致。
- 原有工作流上传和参数映射一致。
- 原有任务、素材和目录数据可见。
- 原有 API 契约测试通过。

### 13.2 V2 功能验收

- 菜单按权限和生成类型配置动态生成。
- 所有生成页只显示本类型工作流。
- 多媒体输入可上传、从素材库选择并预览。
- 任务详情完整展示参数、运行事件和结果。
- 素材库默认定位当天任务结果目录。
- 生成类型可保存草稿、检查、测试、发布、回滚。
- 发布版本可驱动新菜单和新生成页面。

### 13.3 响应式验收

至少覆盖：

- 360×800、390×844 手机。
- 768×1024 平板。
- 1366×768、1440×900、1920×1080 桌面。

不得出现：主要操作不可见、表单被裁剪、底部导航遮挡内容、横向滚动导致无法提交、媒体播放器超出屏幕。

### 13.4 自动化测试建议

- 后端：配置校验、版本发布、回滚、权限、历史兼容。
- 前端单元：参数渲染、联动规则、菜单裁剪、状态标签。
- E2E：登录 → 进入生成类型 → 选择素材 → 提交 → 查看任务 → 查看结果。
- 视觉回归：Dashboard、生成页、任务页、素材库、生成类型编辑器的关键断点截图。

## 14. 发布指标与监控

灰度期间重点观察：

- V2 页面加载失败率。
- 前端未捕获异常。
- 任务提交成功率与 V1 对比。
- 任务最终成功率与 V1 对比。
- 素材首帧/缩略图加载耗时。
- 生成类型配置发布失败原因。
- V2 → V1 主动切换率。
- 移动端任务提交完成率。

如果任务提交成功率、任务最终成功率明显低于 V1，或出现历史数据不可访问，应立即关闭 V2 默认入口并回退。

## 15. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 新版重构影响稳定版 | 路由和目录隔离、契约测试、功能开关 |
| Glassmorphism 降低可读性 | 表格/正文提高不透明度，执行对比度检查 |
| 动态参数配置过度复杂 | 固定组件、固定位置、八步向导，不做自由画布 |
| 配置发布破坏任务复现 | 不可变发布版本，任务记录版本 ID 和参数快照 |
| 移动端复杂配置难用 | 简单管理移动化，复杂编辑使用逐步页并推荐桌面端 |
| 素材多导致页面卡顿 | 缩略图、分页/虚拟列表、并发限制、Blob 释放 |
| V1/V2 API 行为分叉 | 复用稳定执行接口，扩展使用 `/api/v2` |

## 17. 评审决策点

进入开发前需确认：

1. V2 是否固定使用 `/v2` 独立路由作为首期入口。
2. 新菜单名称和层级是否冻结。
3. Glassmorphism 深色主题是否作为首发主题。
4. 生成类型配置是否采用八步固定向导。
5. 首期是否同时开发“批次任务”独立页面。
6. 移动端是否仅支持生成类型的轻量管理。
7. `/api/v2` 和生成类型版本模型是否按本文方案执行。

上述决策冻结后，阶段 0 和阶段 1 可正式启动。

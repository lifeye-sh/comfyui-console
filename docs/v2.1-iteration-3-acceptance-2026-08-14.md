# V2.1 第 3 轮验收记录

> 日期：2026-08-14  
> 范围：故事文档导入、CreativeJob 与独立 Story Worker

## 后端交付

- 新增 `source_documents`、`source_chapters`、`source_paragraphs` 三层源文档结构和 `0009` Alembic 迁移。
- 支持 TXT、DOCX、EPUB 导入；DOCX/EPUB 使用 Python 标准库解析，不增加生产部署依赖。
- 原始文件进入现有素材库“上传素材”目录，并通过 `ProjectResourceLink` 关联短剧项目。
- 同一用户、同一项目、相同文件内容使用稳定幂等键，重复上传不会重复创建文档和任务。
- 文档大小限制为 50MB；归档格式同时限制条目数和解压后总体积，避免压缩炸弹占用资源。
- CreativeJob 支持排队、运行、成功、失败、取消中、已取消状态，以及进度、日志、错误和重试次数。
- Story Worker 与 ComfyUI Dispatcher 独立，由应用生命周期单独启动和停止；解析与持久化在线程中执行，不阻塞登录/API 事件循环。
- Worker 启动时回收心跳超时任务，并在达到恢复上限后标记失败。
- 所有文档和作业 API 均按当前用户隔离。

## 前端交付

- 新增 `/v2/drama/projects/:id/import` 文档导入工作台。
- 项目概览新增“导入故事文档”入口。
- 支持大面积点击/拖放选区、扩展名与文件大小前置校验、上传进度。
- 展示解析任务进度、状态、时间、错误和可展开日志。
- 排队/运行任务支持取消，失败/取消任务支持重新解析。
- 已导入文档展示格式、章节数、段落数和总字数。
- 仅在存在活动任务时轮询，离开页面立即停止定时器；桌面双栏、移动端单栏。

## 关键接口

```text
POST /api/v2/short-drama/projects/{id}/imports
GET  /api/v2/short-drama/projects/{id}/documents
GET  /api/v2/short-drama/jobs
GET  /api/v2/short-drama/jobs/{id}
POST /api/v2/short-drama/jobs/{id}/cancel
POST /api/v2/short-drama/jobs/{id}/retry
```

- 导入、素材关联、幂等、结构化落库、取消、重试和跨用户隔离均有 API/服务测试。

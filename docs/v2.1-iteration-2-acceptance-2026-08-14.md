# V2.1 第 2 轮验收记录

> 日期：2026-08-14
> 范围：短剧项目、创作简报与项目概览

## 后端交付

- 短剧项目新建、详情、修改、软删除和恢复 API。
- 项目名称/简介搜索、状态筛选、服务端分页和已删除项目查询。
- 项目列表聚合分集、场景和镜头数量，无逐项目 N+1 请求。
- 创作简报读取和更新 API。
- 项目概览聚合分集、场景、镜头、Take 和 CreativeJob 数量。
- 所有查询默认只访问当前用户数据，管理员也不默认混看普通用户项目。
- 项目和创作简报使用 `lock_version` 乐观锁；过期更新返回 HTTP 409。
- 项目软删除前检查排队或运行中的关联任务。
- 创建、修改、删除、恢复和简报保存写入审计日志。
- 短剧模块关闭时业务接口拒绝访问，状态接口仍可用于前端回退。

## 前端交付

- 真实项目列表、搜索、分页、空状态和错误状态。
- 已删除项目列表、删除和恢复操作。
- 四种创作起点：一句话创意、故事大纲、完整剧本、小说/文档。
- 新建项目表单覆盖项目信息和成片规格。
- 创建成功后直接进入项目概览。
- 项目概览显示生产阶段、分集/场景/镜头/作业统计。
- 创作简报支持防抖自动保存和手动立即保存。
- 自动保存保留乐观锁，保存期间继续输入不会被旧响应覆盖。
- 未保存或保存失败时刷新、关闭和路由离开提供保护提示。
- 桌面端与移动端响应式布局。

## 关键接口

```text
GET    /api/v2/short-drama/projects
POST   /api/v2/short-drama/projects
GET    /api/v2/short-drama/projects/{id}
PATCH  /api/v2/short-drama/projects/{id}
DELETE /api/v2/short-drama/projects/{id}
POST   /api/v2/short-drama/projects/{id}/restore
GET    /api/v2/short-drama/projects/{id}/brief
PUT    /api/v2/short-drama/projects/{id}/brief
GET    /api/v2/short-drama/projects/{id}/overview
```

## 验收重点

- 用户 A 无法读取、修改或列出用户 B 的项目。
- 使用旧 `lock_version` 修改项目或简报返回 409。
- 删除后项目不出现在正常列表，可从已删除列表恢复。
- 搜索和分页由服务端执行。
- 页面轮询或其他后台任务不会整体替换正在编辑的简报。
- 新建项目到保存创作简报的完整链路可用。

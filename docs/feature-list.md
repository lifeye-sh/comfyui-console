# comfyui-console 系统功能清单（整合版）

> 版本：v0.2　日期：2026-08-05
> 说明：本清单 = 架构 v0.1 规划能力 + 借鉴"AI绘视玩家"现有系统能力（见 [existing-system-analysis.md](reference/existing-system-analysis.md)）的整合结果。
> 图例：🆕 = 借鉴现有系统新增；⭐ = 相对现有系统的差异化增强；里程碑列对应架构文档 M1–M4。

## 1. 用户与认证 ⭐

| 功能 | 说明 | 里程碑 |
| --- | --- | --- |
| 登录 / JWT 认证 | 访问令牌 + 刷新令牌；现有系统无认证，此为补齐项 | M1 |
| 用户管理 | admin / user 角色；管理员建号（MVP 不开放注册） | M1 |
| 操作权限控制 | 删除、API 修改等敏感操作按角色拦截 ⭐ | M3 |

## 2. 工作流管理

| 功能 | 说明 | 里程碑 |
| --- | --- | --- |
| 工作流导入 | 上传 UI 格式 JSON（画布）+ API 格式 JSON（可执行） | M2 |
| 版本管理 | 每次变更生成版本快照，任务绑定版本可复现 | M2 |
| 参数化（ParamSchema） | 声明可变参数：节点 ID + 字段路径 + 类型 + 约束（文本/数字/种子随机/图片槽位等）；含输出节点编号映射（对应现有系统"API 管理-输出节点编号"） | M2 |
| 生成类型分类 🆕 | 内置分类——图片：文生图、单图生图、双图生图、三图生图、混合生图；视频：文生视频、图生视频、首尾帧、视频参考、数字人；音频：文生语音(TTS)、音乐生成、音频转换（变声/克隆）；支持自定义分类 | M2 |
| 分类默认工作流 🆕 | 每个生成类型可设默认工作流（对应现有系统"设为默认 API"），混合批次按类型自动路由 | M2 |
| 检索与组织 | 按名称/标签/分类搜索；封面图（取资源库图片） | M2 |

## 4. 任务发布（单任务 + 批量）

| 功能 | 说明 | 里程碑 |
| --- | --- | --- |
| 单任务发布 | 选工作流 → ParamSchema 渲染参数表单 → 提交 | M1 |
| 按类型平铺的生成页面 🆕 | 对齐现有系统结构：图片/视频/音频生成菜单下每类型一个子页面，绑定该类型默认工作流与专属任务行列（参考图槽位数、视频/音频参数）；配置驱动，新增分类并设默认工作流后页面自动出现在菜单中 | M2 |
| 批量任务行（Batch）🆕 | 任务行表格：添加行、逐行设置提示词/参数/参考图；行级默认值（宽、高、种子、随机种子） | M2 |
| 文件导入任务行 🆕 | 从 CSV/Excel 导入任务行，可指定起始行号、列号；支持"追加现有队列"或"清空后导入" | M2 |
| 混合类型批次 🆕 | 同一批次混用多种生成类型的任务行，各行按类型路由到对应默认工作流 | M3 |
| 批次保存/复用 🆕 | 输入任务名称保存整批任务行，后续可重新加载执行（对应现有系统 SAVE） | M2 |
| 逐行生成 / 批量生成 🆕 | 单行独立提交；或整批入队（无任务行时按钮禁用） | M2 |
| 取消任务 | 取消排队中/执行中任务（调用节点 `/interrupt`）；支持整批取消 | M1 |

## 附二：整合后平台总体菜单结构（建议）

参考 AI绘视玩家的分组方式，图片/视频/音频生成各自作为独立菜单组，类型平铺；桌面端侧边栏 / 移动端入口，一套路由双端适配：

```text
comfyui-console
├── 素材库（首页，生成结果卡片墙）          /
├── 图片生成
│   ├── 文生图                            /gen/image/t2i
│   ├── 单图生图                          /gen/image/i2i
│   ├── 双图生图                          /gen/image/i2i-2
│   ├── 三图生图                          /gen/image/i2i-3
│   └── 混合生图                          /gen/image/mixed
├── 视频生成
│   ├── 文生视频                          /gen/video/t2v
│   ├── 图生视频                          /gen/video/i2v
│   ├── 批量首尾帧                        /gen/video/start-end
│   ├── 视频参考                          /gen/video/reference
│   └── 数字人                            /gen/video/digital-human
├── 音频生成 🆕
│   ├── 文生语音（TTS/配音）              /gen/audio/tts
│   ├── 音乐生成                          /gen/audio/music
│   └── 音频转换（变声/克隆）             /gen/audio/convert
├── 任务管理
│   ├── 执行看板（队列实时监控）           /tasks/board
│   ├── 完成记录                          /tasks/done
│   └── 操作记录                          /tasks/logs
├── 资源库
│   ├── 全部资源（输入/输出统一检索）      /resources
│   └── 参考视频（上传 + 抽帧取图）        /resources/videos
├── 工作流
│   ├── 工作流列表（按生成类型分类）        /workflows
│   └── 分类与默认工作流设置               /workflow-categories
├── 提示词库（含分类管理）                 /prompts
├── 节点管理（注册/健康/能力标签）         /nodes
└── 系统设置
    ├── 用户与权限                         /settings/users
    ├── 分享管理                           /settings/shares
    └── 平台设置                           /settings
```

**关键实现约束（与 AI绘视玩家的本质差异）：** 菜单结构平铺，但页面实现不重复——所有生成子页是同一个「批量任务表格」视图按生成类型的实例化：进入页面即选中该类型分类、绑定其默认工作流与专属 ParamSchema 任务行列（参考图槽位、时长/帧数/块交换、音频参数等）。新增生成类型时，管理员在「分类与默认工作流设置」添加分类并设定默认工作流，对应子页自动出现在菜单中，无需开发新页面。

**音频生成组**为本次新增（现有系统无此组）：文生语音（TTS/配音）、音乐生成、音频转换（变声/克隆）三类先行占位，具体子页随音频类工作流导入后启用；音频参数（时长、采样率、参考音频等）由 ParamSchema 扩展音频类型槽位支持。

移动端底部 Tab 收敛为四个高频入口：**发布**（打开生成类型选择页 → 进入具体类型页）、**任务**（/tasks/board）、**素材**（/）、**我的**（/settings）；其余页面经"我的"或首页导航进入。

# comfyui-console 功能详细规格

> 版本：v0.3　日期：2026-08-05
> 目标：将系统功能清单细化为可用于原型设计、接口设计和开发验收的功能规格。

## 0. 统一约定

### 0.1 角色

系统至少包含两类角色：普通用户和管理员。普通用户可发布任务、查看自己的任务与资源、使用已授权工作流；管理员可管理用户、节点、工作流、提示词、系统配置和全局资源。

### 0.2 统一任务状态

`DRAFT` 草稿、`PENDING` 排队中、`DISPATCHING` 调度中、`QUEUED` 已提交节点、`RUNNING` 执行中、`FINALIZING` 整理输出、`SUCCESS` 成功、`FAILED` 失败、`CANCELLED` 已取消。

### 0.3 统一生成页结构

图片生成、视频生成、音频生成的每一个子页都采用同一套页面骨架，但根据生成类型加载不同的参数模板：顶部为类型标题和默认工作流；中部为全局参数；主体为批量任务行表格；底部为导入、保存、逐行生成和批量生成操作。

所有生成页必须支持桌面端和移动端。桌面端使用表格布局，移动端将每一行折叠为任务卡片；不得因为移动端而删除关键字段。

### 0.4 通用批量任务行

每个批次包含批次名称、生成类型、工作流版本、全局参数和任务行。任务行至少包含：行号、提示词、负面提示词、参考资源、尺寸/时长等类型参数、种子、状态、预览结果和行操作。

通用操作包括添加任务行、复制任务行、删除任务行、清空任务行、导入 CSV/Excel、追加导入、清空后导入、保存批次、逐行生成、批量生成、取消批次和重试失败行。

通用规则：没有任务行时批量生成按钮禁用；提交前必须校验必填参数和资源格式；已提交的任务行不可直接编辑，需要复制或重试；批量提交应支持并发数量限制。

## 1. 素材库 / 首页

### 1.1 页面目标

集中展示平台生成和上传的图片、视频、音频资源，支持快速预览、筛选、下载、删除和再次生成。

### 1.2 页面组成

页面包括资源类型筛选（全部/图片/视频/音频）、来源筛选（生成结果/输入资源）、任务类型筛选、关键词搜索、时间范围、排序方式、卡片网格、分页或加载更多。

资源卡片显示缩略图或音频封面、资源名称、生成类型、任务名称、创建时间、状态和选中框。图片和视频显示预览；音频显示播放器、时长和波形占位图。

### 1.3 操作

单项操作包括预览、下载、查看详情、复制资源链接、创建分享链接、再次使用、删除。批量操作包括全选、取消全选、批量下载、批量分享和批量删除。

删除必须二次确认。任务关联的输出资源删除后，任务记录保留但资源状态标记为已删除；默认进入回收站而非立即物理删除。

### 1.4 接口

`GET /api/v1/resources`、`GET /api/v1/resources/{id}`、`GET /api/v1/resources/{id}/file`、`POST /api/v1/shares`、`POST /api/v1/resources/{id}/reuse`、`DELETE /api/v1/resources/{id}`。

### 1.5 验收标准

打开首页可看到分页资源；筛选条件能组合使用；预览不会加载原图；删除后卡片立即消失并可在回收站恢复；移动端卡片可正常预览和下载。

## 2. 图片生成

图片生成菜单包含文生图、单图生图、双图生图、三图生图和混合生图。

### 2.1 文生图

页面参数包括全局提示词 1、全局提示词 2、正向提示词、负向提示词、宽度、高度、批次数量、种子、随机种子和生成工作流。全局提示词按系统定义的拼接规则与行提示词合并，页面必须展示最终发送给工作流的提示词预览。

任务行操作包括编辑提示词、从提示词库选择、复制、删除、逐行生成和查看预览。宽高必须为正整数并限制最大像素总量；随机种子开启时忽略手工种子。

### 2.2 单图生图

在文生图字段基础上，每行增加一张参考图片资源槽位，可从本地上传、素材库选择或移动端拍照/相册选择。必须校验图片 MIME、大小和分辨率；没有参考图时禁止提交。

### 2.3 双图生图与三图生图

双图生图必须提供参考图 1、参考图 2；三图生图必须提供参考图 1、参考图 2、参考图 3。每个槽位支持替换、清除、预览和从资源库选择。任务提交时平台按 ParamSchema 将资源 ID 转换为目标节点所需的文件名。

### 2.4 混合生图

同一批次允许混用文生图、单图生图、双图生图和三图生图。每行必须显示生成子类型，并加载该子类型的参数模板。管理员必须为已启用的子类型配置默认工作流，否则该类型行不能提交。

批量提交时逐行按类型分发，某一类型配置缺失不能阻塞其他类型，但该行必须标记为校验失败并说明原因。

### 2.5 图片生成通用接口

`GET /api/v1/generation-types/image`、`GET /api/v1/workflows?category=image`、`POST /api/v1/batches`、`POST /api/v1/batches/{id}/import`、`POST /api/v1/batches/{id}/submit`、`POST /api/v1/tasks/{id}/cancel`。

### 2.6 图片生成验收标准

用户可以通过提示词库快速填充提示词；可以上传或选择参考图；单行生成不会影响其他行；批量生成会生成可追踪的批次和任务行；每行能显示实时状态和结果；失败行可单独重试。

## 3. 视频生成

视频生成菜单包含文生视频、图生视频、批量首尾帧、视频参考和数字人。

### 3.1 文生视频

参数包括提示词、负面提示词、宽度、高度、时长或帧数、帧率、种子、随机种子、块交换/显存优化参数和工作流。页面必须明确区分“时长（秒）”与“帧数”，不能使用含义不清的字段名称。

提交前校验宽高、帧数、帧率、预计显存和文件大小。生成过程中显示进度、已用时间、预计剩余时间（若节点提供）和取消按钮。

### 3.2 图生视频

在文生视频基础上增加首帧/参考图片。支持上传、资源库选择和移动端拍照。参考图尺寸与视频尺寸不一致时，提供裁剪、等比缩放或交给工作流处理的选项。

### 3.3 批量首尾帧

每行包含首帧、尾帧、转场提示词、视频参数和种子。首帧与尾帧均为必填资源；允许通过 CSV/Excel 导入图片路径或资源引用，但导入后必须显示资源匹配结果，未匹配项不能提交。

### 3.4 视频参考

每行包含参考图、参考视频、提示词、帧数、帧率、块交换和种子。参考视频须校验视频格式、时长、大小和可读性；支持从参考视频管理页选择已有资源。

### 3.5 数字人

每行包含参考人物图、参考视频、音频 1、音频 2、控制素材 1、控制素材 2、提示词和生成参数。参数应按场景分组：人物、动作、音频、控制、输出。音频轨道可只填一条；多人模式必须明确人物与音频的对应关系。

页面必须明确“时长（秒）”“帧数”“帧率”的关系，并在输入变化时显示预计视频时长。

### 3.6 视频接口与验收

使用统一批次接口，类型参数由 `ParamSchema` 决定。视频输出回收入库后保存封面、视频文件、时长、分辨率、帧率和 MIME 信息。验收要求：大文件上传可显示进度；生成中可取消；完成后可在线播放、下载和分享；失败能展示节点错误摘要。

## 4. 音频生成

音频生成作为独立一级菜单，首期包含文生语音、音乐生成和音频转换。

### 4.1 文生语音（TTS/配音）

参数包括文本、声音/说话人、语言、语速、音调、情绪、采样率、输出格式和种子（工作流支持时）。支持文本编辑、批量文本导入、按行选择声音。文本长度必须限制在工作流和服务允许范围内。

### 4.2 音乐生成

参数包括音乐描述、风格、情绪、时长、是否人声、歌词、采样率和输出格式。歌词为可选项；时长必须在系统配置范围内。结果卡片提供播放器、波形、下载和再次生成。

### 4.3 音频转换

支持变声、音色转换、声音克隆等工作流。参数包括源音频、参考音色、目标语言/音色、强度和输出格式。必须明确获得用户对上传音频的使用授权提示；不得默认公开音频资源。

### 4.4 音频通用规则

支持 WAV、MP3、M4A 等配置允许的格式；上传时读取时长、采样率、声道和大小；输出入库时生成波形摘要和元数据。移动端支持录音文件选择，不要求首期直接录音。

## 5. 任务管理

### 5.1 执行看板

按排队中、执行中、成功、失败、已取消分组展示任务。支持关键词、生成类型、批次、状态、节点、用户和时间范围筛选。任务卡显示任务名称、类型、批次行号、节点、进度、创建时间和操作按钮。

操作包括查看详情、取消、重试、复制任务、调整优先级（有权限时）和打开结果。批次视图显示整体进度，例如成功数/总数、失败数和完成百分比。

### 5.2 完成记录

对应历史完成任务页面。支持关键词、类型、时间范围和用户筛选，分页显示任务名称、类型、任务 ID、完成时间、耗时、结果数量和操作。操作包括查看结果、下载、再次生成和删除结果资源。

### 5.3 操作记录

记录创建批次、导入任务、提交、取消、重试、删除、修改工作流、修改 API 配置等行为。普通用户只能查看自己的记录，管理员可按用户、操作类型和时间查询全局记录。

### 5.4 任务详情

详情页包含任务基本信息、工作流版本、参数快照、输入资源、节点信息、实时事件时间线、输出资源、错误信息和重试记录。任务完成后参数和工作流版本不可变，保证复现。

## 6. 资源管理

### 6.1 资源类型

支持图片、视频、音频三类资源，并区分输入资源、输出资源、参考资源、缩略图和封面。资源记录保存哈希、文件名、MIME、大小、尺寸/时长、存储位置、归属用户、来源任务和可见性。

### 6.2 参考视频

独立页面支持名称搜索、视频上传、预览、删除、抽帧和保存帧图片。抽帧操作支持指定时间点、间隔或帧号，生成的图片与源视频建立关联。

### 6.3 分享

分享资源或任务结果时生成令牌链接，可设置过期时间、访问密码和下载权限。分享页不暴露内部节点地址、用户信息和敏感参数；资源所有者可以撤销分享。

## 7. 工作流与 API 管理

### 7.1 工作流列表

支持按名称、生成大类、生成类型、标签、节点能力和状态查询。卡片显示名称、版本、默认标记、封面、适用类型和更新时间。

### 7.2 工作流导入与版本

支持导入 UI JSON、API JSON、ParamSchema 和封面。导入时校验 JSON 结构、节点引用和输出节点；每次发布生成不可变版本。工作流可复制、停用、恢复和设置默认。

### 7.3 分类与默认工作流

生成大类固定为图片、视频、音频；生成类型可扩展。每个类型可以设置默认工作流、默认节点能力要求、输出节点编号和参数模板。未配置默认工作流的类型在菜单中可显示但不可提交，并给出管理员配置提示。

### 7.4 工作流执行测试

管理员可以选择测试输入和参数，在指定节点执行一次，查看节点响应、输出和错误。测试任务必须标记为测试任务，避免混入普通用户历史。

### 7.5 接口

`GET/POST /api/v1/workflows`、`POST /api/v1/workflows/{id}/versions`、`POST /api/v1/workflows/{id}/test`、`GET/POST /api/v1/generation-types`、`PATCH /api/v1/generation-types/{id}/default-workflow`。

## 8. 提示词库

支持提示词名称、正文、负面提示词、分类、标签、备注、封面、作者和可见性。支持搜索、分类筛选、收藏、复制、编辑、删除和在生成页一键使用。

批次级全局提示词 1/2 与行级提示词的拼接规则必须可配置并在页面展示最终文本。删除提示词不能影响已提交任务的参数快照。

接口：`GET/POST /api/v1/prompts`、`PATCH/DELETE /api/v1/prompts/{id}`、`GET/POST /api/v1/prompt-categories`。

## 9. ComfyUI 节点管理

支持节点名称、HTTP 地址、WebSocket 地址、认证信息、标签、最大并发数和启用状态。新增或修改节点后可执行连接测试、读取系统状态、读取队列和读取 `/object_info`。

节点列表显示在线、离线、繁忙、维护状态、显存摘要、当前任务和最近心跳。管理员可启用/禁用节点、设置并发、设置标签和查看节点日志。敏感地址和凭证仅管理员可见。

接口：`GET/POST /api/v1/nodes`、`PATCH/DELETE /api/v1/nodes/{id}`、`POST /api/v1/nodes/{id}/probe`、`GET /api/v1/nodes/{id}/stats`。

## 10. 用户、权限与系统设置

用户管理支持创建、禁用、重置密码、分配角色和查看活动记录。权限至少区分：发布任务、查看本人资源、查看团队资源、删除资源、管理工作流、管理节点、管理系统设置。

平台设置包括项目名称、默认节点、资源存储路径、单文件大小上限、允许的 MIME 类型、任务超时、默认重试次数、并发上限、分享有效期、WebSocket 配置和通知配置。修改高风险配置需记录审计日志。

## 11. 通用异常与安全要求

前端必须区分参数校验失败、资源上传失败、节点不可用、工作流执行失败、权限不足和系统异常，并提供可操作的中文提示。长任务页面刷新后必须通过接口恢复状态，不得只依赖浏览器内存。

系统必须默认启用认证；所有资源下载、任务查询和修改操作执行归属校验；文件名必须清洗，禁止路径穿越；上传文件只按 MIME 和内容探测结果处理；分享令牌使用高熵随机值；节点凭证加密或安全存储；删除、取消和重试操作必须记录审计事件。

## 12. 总体验收场景

用户登录后能够配置一个 ComfyUI 节点，导入一个文生图、文生视频或文生语音工作流，配置参数模板和默认工作流；从对应的图片生成、视频生成或音频生成菜单进入页面；添加或导入多行任务；上传输入资源；逐行或批量提交；在任务看板查看进度；完成后在素材库播放、预览、下载和分享结果；失败时能查看错误并重试；移动端能够完成发布、查看和结果保存的完整闭环。

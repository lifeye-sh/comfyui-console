# 漫剧制作模块第一阶段功能规格

> 状态：功能冻结候选（Phase 1）  
> 范围：项目创建 → 项目总览 → 第 1 集剧本策划 → AI 拍摄清单 → 角色、场景与道具确认  
> 不包含：账号、充值、会员、镜头图片制作、视频、配音、剪辑和成片导出  
> 视觉与完整平台说明见 [界面设计规范](./bigbanana-ui-design-spec.md) 与 [平台复刻规范](./bigbanana-platform-replication-spec.md)。

## 1. 阶段目标

第一阶段交付一个可真正推进项目的前半段生产闭环：

```text
项目库
→ 一键创建项目和第 1 集
→ 剧本策划（小说生成分镜 / 分镜生成分镜）
→ AI 后台生成拍摄清单
→ 人工编辑并确认拍摄清单
→ AI 提取角色、场景、道具
→ 生成、上传或绑定素材
→ 确认跨镜头一致性素材
```

“完成第一阶段”的含义不是生成了若干文本，而是项目已经拥有：

- 已确认的单集拍摄清单版本。
- 已确认的角色、场景和关键道具领域实体。
- 每个必需角色和场景至少一个已采用素材版本。
- 后续镜头设计可稳定引用的角色服装和项目素材 ID。

## 2. 产品边界与术语

### 2.1 统一术语

| 用户界面 | 领域对象 | 说明 |
| --- | --- | --- |
| 项目 | `ShortDramaProject` | 漫剧生产容器 |
| 集数 | `Episode` | 单集生产边界 |
| 拍摄清单 | `ScriptManifestVersion` | AI 分析后的版本化场次与镜头清单 |
| 角色 | `Character` | 项目级稳定人物身份 |
| 基础造型 | `Character.primary_resource_id` | 角色默认外观 |
| 服装变体 | `CharacterVariant` | 同一人物的服装/妆发/状态变化 |
| 场景 | `Location` | 跨镜头复用的空间概念素材；不是 `Scene` 场次 |
| 场次 | `Scene` | 剧本结构中的一个叙事段落 |
| 道具 | `Prop` | 跨镜头连续性物件 |
| 素材库 | `Resource` / `ResourceFolder` | 全平台唯一媒体库；不再建立漫剧资产库 |

### 2.2 明确排除

- 不实现账号中心、积分、充值、会员和商业授权入口。
- 不暴露“V2.1”“V3 导演模式”等技术版本概念。
- 不继续扩展旧 V3 九步导演流程。
- 不为漫剧另建媒体文件、任务队列、工作流或素材库。
- 第一阶段不实现镜头关键帧、宫格、视频、配音与剪辑页面；只冻结其上游引用契约。

## 3. 全局信息架构

### 3.1 路由

| 页面 | 路由 |
| --- | --- |
| 项目库 | `/v2/drama/projects` |
| 项目总览 | `/v2/drama/projects/:projectId` |
| 剧本策划 | `/v2/drama/projects/:projectId/episodes/:episodeId/script` |
| 拍摄清单 | `/v2/drama/projects/:projectId/episodes/:episodeId/manifest` |
| 角色与场景 | `/v2/drama/projects/:projectId/episodes/:episodeId/assets` |

旧 `/screenplay`、`/world`、`/storyboard` 和实验性 `/director` 路由不作为新产品入口。必要时保留只读兼容跳转，但不继续新增 UI。

### 3.2 集内导航

集内页面统一使用：

1. 剧本策划。
2. 视觉设定（角色、场景、道具）。
3. 镜头设计（第二阶段）。
4. 剪辑交付（后续阶段）。
5. 提示词库。

拍摄清单是“剧本策划”的 AI 分析结果页，不单独作为顶层阶段。

## 4. 项目库

### 4.1 页面结构

- 无模块侧栏，全宽暖米白页面。
- 顶部：项目库标题、说明、项目数量、近 7 天活跃数、素材沉淀数。
- 顶部操作：语言、返回控制台、新建项目、帮助、系统设置、主题。
- 首屏：继续最近项目、快速查找项目。
- 下方：全部项目、状态筛选和分页。

### 4.2 一键创建

“新建项目”不是向导。点击后在一个事务内：

1. 创建默认项目，名称为“新建项目 YYYY-MM-DD HH:mm”。
2. 创建默认 `ProjectBrief`。
3. 创建第一季容器（如不单独建表则保存在项目设置）。
4. 创建 `Episode(number=1, title=第 1 集, target_duration=60)`。
5. 进入项目总览。

重复点击通过客户端禁用、请求幂等键和后端唯一性共同防重。

### 4.3 项目卡与查询

- 查询：名称、描述、状态、更新时间。
- 卡片：名称、最近编辑时间、角色/场景/道具数量、集数和创建日期。
- 操作：继续编辑、软删除、恢复。
- 活跃 CreativeJob 或 ComfyUI Task 存在时禁止删除，并明确列出阻断任务。

### 4.4 验收

- 从空项目库到第 1 集可编辑入口不超过两次点击。
- 刷新项目库后统计、最近项目和全部项目一致。
- 删除是软删除，恢复后项目和素材引用保持不变。

## 5. 项目总览

### 5.1 首屏

- 左卡：项目状态、完整度、完成项、项目说明、进度和导入/导出。
- 右卡：推荐下一步“先开始第 1 集剧本策划与分镜”。
- 新项目不要求先创建角色和场景。

### 5.2 项目素材

显示角色、场景、道具和世界观计数。点击角色/场景/道具进入当前集视觉设定；底层媒体仍进入全局素材库。

### 5.3 剧集管理

- 展示季、集数、当前状态和最近更新时间。
- 支持添加新集、编辑集标题、软删除空集。
- 第 1 集默认存在；删除最后一集前必须先新增替代集。

### 5.4 小说导入

导入整篇小说支持 `.txt`、`.md`、`.docx` 和粘贴文本。解析、章节识别和拆集使用 `CreativeJob`，刷新后可恢复。确认拆集前不写入正式 Episode。

### 5.5 验收

- 新项目总览能准确显示 1 集、0 角色、0 场景、0 道具。
- “进入剧本策划”总是定位到当前选择集。
- 项目进度由事实数据计算，不由前端硬编码。

## 6. 剧本策划

### 6.1 布局

- 全局导航侧栏。
- 独立滚动的项目配置栏。
- 大型剧本编辑器。
- 配置栏底部固定“生成分镜脚本”。
- 编辑器顶部固定 AI 续写、AI 改写、选段改写和撤回改写。

### 6.2 两种生成分镜模式

界面按钮准确使用：

#### 小说生成分镜

- 适用：没有分镜，只有小说、章节、剧情大纲或剧本。
- 输入：连续文本。
- AI 行为：理解故事、拆场次、规划镜头、生成对白/动作和提示词。
- 空态：故事结构说明、推荐输入类型和正文占位。

#### 分镜生成分镜

- 适用：用户已经编写分镜稿。
- 输入：逐镜文本、Markdown 表格或结构化 JSON。
- AI 行为：保留镜头顺序、对白、任务动作和镜头备注，只补最小缺失字段。
- 空态：并排展示“模板 A · 标准分镜”和“模板 B · 对话驱动”。
- 禁止静默拆分、合并、重排或改写用户镜头；必要调整输出差异候选。

模式切换不删除当前文本。结构不匹配时只显示风险，并允许取消切换。

### 6.3 项目配置

- 项目标题。
- 输出语言：中文、英语、日语、法语、西班牙语。
- 画幅：横屏、竖屏。
- 目标时长：30 秒、60 秒、2 分钟、5 分钟、自定义。
- 按当前视频工作流默认单镜时长估算镜头数量。
- 分镜文本模型：来自 AI 模型配置。
- 视觉风格与参考缩略图。
- 上传图片或从素材库选择图片反推风格。
- 分镜质量校验与自动修复，默认开启。
- 图片、视频、语音能力显示 ComfyUI 工作流绑定状态；第一阶段只实际调用图片工作流。

### 6.4 编辑与版本

- 自动保存采用 800–1200 ms 防抖；失焦立即保存。
- 展示字符数、行数、建议上限和保存状态。
- 保存使用 `lock_version`；冲突时不覆盖服务器版本，进入对比处理。
- AI 续写、全文改写、选段改写都生成候选版本。
- 应用 AI 结果后保留上一版本；撤回恢复到应用前版本。
- 建议单集不超过 8000 字符，但不硬截断已有内容。

### 6.5 生成前检查

- 正文非空且未超出模型上下文能力。
- 输出语言、画幅、时长和模型有效。
- 分镜生成模式与输入结构基本匹配。
- AI Provider 可用。
- 幂等键由 episode、script revision、mode 和配置哈希组成。

### 6.6 验收

- 两种模式的空态、校验与生成 payload 不混用。
- 刷新后恢复最后自动保存内容和生成任务状态。
- AI 修改不会静默覆盖人工文本。

## 7. AI 生成拍摄清单

### 7.1 后台任务

点击生成后创建 `CreativeJob(type=generate_script_manifest)`。阶段进度：

```text
校验输入 → 理解故事/分镜 → 分场 → 拆镜
→ 提取角色/场景/道具 → 编译提示词 → 质量校验 → 保存草稿
```

支持取消、失败重试、超时恢复和旧 revision 结果作废。页面关闭不影响任务。

### 7.2 拍摄清单页面

- 顶部：项目名、总时长、版本、校验状态、保存状态、返回剧本。
- 左侧分析摘要：故事梗概、演员表，可继续显示场景表和道具表。
- 主区：场次 → 镜头纵向清单。

场次字段：序号、空间/地点、子位置、时间、节奏、情绪。

镜头三列：

1. 镜头号、景别、机位、运镜、时长。
2. 画面叙事、动作、对白/旁白、角色引用。
3. 画面提示词、视觉风格、镜头运动、构图、首帧要求、角色一致性和负面约束。

### 7.3 编辑、版本与确认

- 草稿清单可编辑并自动保存。
- AI 原值、用户修改值和当前生效值可追踪。
- 重新生成创建新版本，不覆盖旧版本。
- 确认后的版本不可原地修改；继续修改需派生新草稿。
- 确认时将当前清单物化为现有 Episode/Scene/Shot 当前生产视图，并创建角色、场景、道具草稿。
- `V3GenerationManifest` 是后期生成任务清单，不能复用为本页 `ScriptManifestVersion`。

### 7.4 校验门禁

- 场次和镜头编号唯一且有序。
- 镜头必需字段完整。
- 总时长与目标时长差异在允许范围。
- 角色、场景、道具引用能解析到稳定临时键。
- Blocker 清零后才能确认并进入视觉设定。

### 7.5 验收

- 任务成功后自动进入对应清单版本。
- 编辑、刷新、冲突、重新生成和确认均不丢失历史。
- 确认后角色/场景/道具数量与清单引用一致。

## 8. 角色、场景与道具

### 8.1 进入方式

确认拍摄清单后创建项目级草稿实体并进入“角色与场景 / ASSETS & CASTING”。重复进入不得重复创建同名实体；使用稳定提取键完成合并。

### 8.2 顶部工具栏

- 素材库。
- 图片生成类型与 ComfyUI 工作流绑定状态。
- 横屏/竖屏。
- 角色、场景、道具数量与待确认数量。
- 保存状态和“进入镜头设计”（第一阶段只显示门禁状态）。

### 8.3 角色卡

- 三列大卡。
- 主形象、选择框、名称、性别、年龄/身份、服装变体数量。
- 重新生成、上传、从素材库替换。
- 可编辑角色提示词：身份、面部、发型、服装、姿态表情、技术质量。
- 生成图片、保存到素材库、删除。
- 待确认、已确认、需修改以及生成任务状态。

每次生成、上传、替换都创建素材版本；明确采用后才更新当前主形象。

### 8.4 服装变体

- 点击“服装变体”打开 `WARDROBE & VARIATIONS` 弹窗。
- 左栏为基础造型和身份提示词。
- 右栏为服装列表、变体名称、视觉描述和新增操作。
- 生成锁定角色身份，只改变服装、配饰、妆发和剧情状态。
- 变体可重新生成、上传、采用、保存到素材库和删除。
- 被镜头引用的变体删除前必须完成替换。

第一阶段落地 `ShotCharacterBinding` 数据契约；实际镜头侧选择器在第二阶段启用。选择优先级：镜头指定 → 场次继承 → 基础造型。

### 8.5 场景与道具卡

场景和道具复用同一个 `ProjectAssetCard`：

- 媒体区、标题区、提示词、生成/上传、素材库、删除和版本状态共用。
- 场景扩展子位置、时间、氛围、空间结构、陈设、光线、天气、色板和镜头可用方向。
- 道具扩展分类、归属角色、出现范围和连续性说明。
- 未设置提示词时允许上传，但生成前必须编辑或采用 AI 补全候选。

### 8.6 素材库规则

- 所有图片最终登记为 `Resource`。
- 项目实体只保存 `Resource` 引用与领域描述。
- “保存到素材库”不复制文件，只补充项目、实体类型、版本和生成来源元数据。
- 删除被引用素材前显示影响范围并默认软删除。

### 8.7 阶段门禁

- 每个拍摄清单必需角色至少一个已采用基础造型。
- 每个必需场景至少一个已采用概念素材。
- 关键道具必须已确认；非关键道具可标记后补。
- 所有生成任务终态明确，无悬挂任务。

### 8.8 验收

- 角色、场景和道具能生成、上传、替换、采用、保存与恢复版本。
- 服装变体不改变基础角色身份。
- 变更已采用素材会准确标记受影响的下游依赖。

## 9. 状态与错误契约

### 9.1 通用保存状态

`clean → dirty → saving → saved`；失败进入 `save_failed`，冲突进入 `conflict`。

### 9.2 CreativeJob

`queued → running → succeeded | failed | cancelling → cancelled`。

### 9.3 素材实体

`unconfigured → ready_to_generate → queued → generating → pending_review → adopted`；失败进入 `failed`，依赖变化进入 `stale`。

### 9.4 错误展示

- 页面级：无权限、项目不存在、模块关闭。
- 区块级：模型/工作流未绑定、拍摄清单不完整。
- 卡片级：单个角色/场景/道具生成失败。
- 字段级：输入格式、必填项和并发冲突。

错误信息必须给出恢复操作，不只显示错误码。

## 10. 数据复用与新增缺口

### 10.1 直接复用

- `ShortDramaProject`、`ProjectBrief`、`Episode`、`Scene`、`Shot`。
- `Character`、`CharacterVariant`、`Location`、`Prop`。
- `CreativeJob`、AI Provider、Prompt Template、Generation Record。
- `GenerationType`、`WorkflowVersion`、`Task`、`Resource`、`ProjectResourceLink`。
- owner 隔离、审计、WebSocket 与软删除模式。

### 10.2 需要新增或扩展

- `ScriptManifestVersion`、Manifest 场次/镜头版本数据。
- `ProjectAssetVersion`：角色基础图、服装、场景、道具的媒体版本。
- `ShotCharacterBinding`：镜头角色服装绑定。
- `CharacterVariant` 的状态、版本、来源和采用信息。
- 项目默认创建 Episode 的事务服务。
- 项目列表角色/场景/道具计数与完整度查询。
- Episode 剧本文本模式、自动保存版本和生成配置。

### 10.3 仅借鉴、不直接复用

- V3 Manifest 的版本、审批、依赖和 stale 服务模式可以抽取。
- `V3GenerationManifest` 的数据语义是后期任务清单，不等同于拍摄清单。
- `DirectorWorkbench.vue`、旧 World/Storyboard 页面不作为新 UI 基础。

## 11. 第一阶段完成定义

以下条件全部满足才算完成：

- 项目库、项目总览、剧本策划、拍摄清单、角色与场景五个页面完成。
- 一键创建默认项目和第 1 集。
- 两种剧本模式、自动保存、AI 改写和版本恢复可用。
- 拍摄清单后台生成、恢复、编辑、版本化和确认可用。
- 角色、场景、道具自动提取与人工修订可用。
- 图片生成接入现有 ComfyUI 工作流和任务系统。
- 服装变体与镜头绑定数据契约落地。
- 素材统一进入现有素材库。
- 后端权限、幂等、并发和引用完整性测试通过。
- 前端构建、关键组件测试和黄金路径 E2E 通过。

# BigBanana 漫剧平台复刻规格说明

> 文档性质：产品需求（PRD）+ 交互规格 + 技术设计 + 验收标准  
> 取证来源：[BigBanana 漫剧平台飞书介绍](https://ocnf8yod3ljg.feishu.cn/wiki/TLjKwROQ0iIyg8kjjDhcU1TlnVg)  
> 取证日期：2026-08-28；源文档页面显示“4 月 27 日修改”  
> 复刻范围：从“基本设置”开始至文档末尾；明确排除登录、注册、账户中心、充值、签到、邀请码和余额体系。
> 集成定位：本平台作为 `comfyui-console` 的“漫剧创作”大型业务模块实现，不新建第二套图片、视频、语音生成基础设施。
> 页面设计：[漫剧创作模块页面与交互设计规格](./bigbanana-ui-design-spec.md)
> 第一阶段冻结范围：[功能规格](./bigbanana-phase1-functional-spec.md) · [开发计划](./bigbanana-phase1-development-plan.md)

## 1. 目标与边界

目标是在 `comfyui-console` 内建设一个“小说/故事 → 剧本 → 拍摄清单 → 角色/场景/道具 → 分镜图 → 视频 → 配音/剪辑 → 成片导出”的完整 AI 漫剧生产模块。它不是单一生成器，而是以“项目—集—镜头”为主轴、以可复用资产和历史版本为支撑的领域工作台；图片、视频、语音的实际执行统一复用现有 ComfyUI 生成类型、工作流、任务调度和素材系统。

### 1.1 必须实现

- 亮色/暗色主题。
- 大语言模型配置，以及基于现有 ComfyUI 生成类型/工作流的图片、视频、语音能力绑定与兼容性校验。
- 项目库、项目总览、单集工作区和最近项目入口。
- 整篇小说导入与自动拆集；手动输入故事、AI 续写、AI 改写。
- 项目参数：标题、输出语言、目标时长、分镜模型、视觉风格。
- 反推视觉风格、生成分镜脚本、全自动模式。
- 角色衣橱、造型九宫格、手工上传造型、素材库、场景和道具。
- 导演工作台、镜头环境校验、4/6/9 宫格分镜、关键帧、镜头拆分。
- 关键帧、网格分镜、多参考图三类视频输入链路。
- 模型能力卡、视频历史版本、图片/宫格历史版本。
- 视频提示词编辑、模型/比例/时长选择、生成、进度、失败重试。
- 配音、成片预览、AI 剪辑、项目工程导入导出、源素材下载。
- 渲染日志和提示词管理。

### 1.2 明确不做

- 用户登录、注册、找回密码、邮箱验证。
- 账户余额、充值、兑换码、邀请返利、签到。
- 套餐、额度计费和支付订单。

### 1.3 复刻原则

- 复刻功能、信息架构和工作流，不直接复制对方品牌名、Logo、插画、水印或专有文案。
- 所有 AI 输出必须允许人工检查、编辑、回退和重生成。
- 任何生成任务都必须异步执行；切换页面不应导致任务中断。
- 文档中“生成分镜脚本时不要关闭或切换页面”属于原平台限制，复刻版应通过后台任务和恢复机制消除该限制。
- 漫剧模块只负责生产意图、领域参数和结果归属；不得复制 `GenerationType`、`Workflow`、`WorkflowVersion`、`Task`、`Resource`、`Node` 或调度器。

在 `comfyui-console` V2 主导航中，“漫剧创作”作为一级业务模块进入；模块内保持上述项目级信息架构。模块里的“模型设置”“素材库”“运行日志”是带漫剧上下文的聚合视图：管理生成类型/工作流时跳转或复用现有系统配置页面，浏览媒体和任务时调用现有素材库、任务管理与运行监控，不复制菜单背后的数据能力。

### 2.1 单集左侧导航

保持源平台截图的固定左栏布局，至少包含：

1. 剧本策划（Script Planning）
2. 视觉设定/角色与场景（Visual Development）
3. 镜头制作/导演工作台（Shot Design / Director Workbench）
4. 成片与导出（Editorial Delivery）
5. 提示词管理（Prompt Library）

左栏顶部显示返回项目总览、项目名称、当前集、创作阶段和完成度；底部提供主题、帮助、设置等非核心入口。

## 3. 核心对象与状态

### 3.1 对象层级

| 对象 | 关键字段 | 说明 |
| --- | --- | --- |
| Project | id、title、language、target_duration、visual_style、status | 漫剧项目 |
| Episode | id、project_id、episode_no、title、script、status | 单集；可独立生产和导出 |
| Shot | id、episode_id、shot_no、shot_type、duration、status | 生产最小单元 |
| Character | name、aliases、description、default_look_id | 项目级角色 |
| CharacterVariant | character_id、name、description、resource_id、status、is_default、version、source | 角色衣橱中的基础造型或服装变体 |
| ShotCharacterBinding | shot_id、character_id、variant_id、inheritance_source | 镜头内角色采用的具体服装；variant_id 为空表示基础造型 |
| Scene | name、description、prompt、images、version | 可跨镜头复用的场景资产 |
| Prop | name、description、prompt、images、version | 武器、令牌、信物等一致性资产 |
| GridStoryboard | shot_id、grid_count、cells、image、version | 4/6/9 宫格及逐格描述 |
| Keyframe | shot_id、kind(start/end)、prompt、image、version | 首帧或尾帧 |
| DramaProductionProfile | project_id、capability_bindings | 项目级图片/视频/语音工作流默认绑定；P0 可存于项目 settings |
| ShotTaskLink | shot_id、task_id、purpose、idempotency_key | 复用现有任务时的领域关联 |
| Take | shot_id、resource_id、source_task_id、status、generation_snapshot | 图片、视频、音频候选版本，媒体信息来自 Resource |
| EditProject | episode_id、timeline、tracks、settings | 非破坏性剪辑工程 |
| CreativeJob | type、target、provider_config_id、status、error | 小说分析、续写、改写、拆镜等 LLM 后台作业 |
| Task / TaskEvent | generation_type_id、workflow_version_id、params、status、progress | 直接复用 comfyui-console 的 ComfyUI 生成任务与事件 |

`GenerationType`、`GenerationTypeConfigVersion`、`Workflow`、`WorkflowVersion`、`Batch`、`Task`、`TaskEvent`、`Resource`、`TaskResource` 和 `Node` 均使用仓库现有模型；漫剧模块不得创建同义表。角色图、场景图、宫格图、视频和配音最终都登记为现有 `Resource`，再通过 `Take` 或领域引用关联到项目和镜头。

### 3.2 状态机

```text
项目：DRAFT → SCRIPTING → ASSETING → SHOOTING → EDITING → COMPLETED

镜头：MISSING
  → ENVIRONMENT_READY
  → STORYBOARD_DESCRIPTION_READY
  → STORYBOARD_IMAGE_READY / KEYFRAME_READY
  → VIDEO_QUEUED
  → VIDEO_RUNNING
  → VIDEO_READY
  → APPROVED

生成任务：QUEUED → RUNNING → SUCCEEDED
                    ├→ FAILED → RETRYING → RUNNING
                    └→ CANCELED
```

现有最终视频的镜头在全自动模式下必须自动跳过。任何人工编辑后的对象都要记录 `edited_by_user=true`，全自动任务不得静默覆盖。

## 4. 全局基本设置

### 4.1 外观设置

- 项目库顶部提供“亮色/暗色”按钮；源截图是带月亮图标的暗色切换。
- 主题选择持久化到浏览器和后端偏好（若平台为单用户，本地存储即可）。
- 暗色模式需覆盖弹窗、卡片、下拉菜单、时间线和媒体预览，不允许只反色主页面。

### 4.2 模型设置

入口：漫剧项目库顶部“系统设置” → “模型设置”。这是一个聚合入口，不是新的模型管理后台。页面分为“大语言模型”和“媒体生成工作流”两部分。

#### 4.2.1 大语言模型

小说解析、AI 续写/改写、结构化拆集、分镜脚本和提示词优化继续使用现有 `AIProviderConfig`/OpenAI 兼容端点：显示名称、API Base URL、模型名、密钥、超时、连接测试、启用状态和默认配置。密钥只展示掩码并加密存储。

#### 4.2.2 图片、视频、语音

图片、视频、语音不在漫剧模块中配置供应商 API 或“模型 ID”，而是选择 `comfyui-console` 已发布的生成类型与 ComfyUI 工作流版本：

- `GenerationType` 决定媒体类型、业务类型、参数模板和默认工作流。
- `GenerationTypeConfigVersion` 提供已发布、可审计的页面配置与能力元数据。
- `Workflow`/`WorkflowVersion` 保存 ComfyUI API JSON、参数映射和输出映射。
- `Node` 与现有调度器负责节点选择、并发、提交、进度、重试、恢复和结果回收。
- `Resource`/`TaskResource` 负责输入素材和生成结果，不复制文件存储。

漫剧模型设置实际配置的是“能力槽位绑定”：

| 能力槽位 | 媒体类型 | 可绑定的现有生成类型/工作流 |
| --- | --- | --- |
| 角色定妆、角色造型 | image | 文生图、参考图生图、多参考图生图 |
| 场景、道具 | image | 文生图、参考图生图 |
| 宫格分镜 | image | 文生图或多参考图生图 |
| 起始帧、结束帧 | image | 文生图、图生图、局部重绘 |
| 关键帧视频 | video | 图生视频、首尾帧视频 |
| 宫格视频 | video | 接受宫格图片输入的视频工作流 |
| 多参考视频 | video | 接受首帧及多张角色/场景/道具图的视频工作流 |
| 旁白、角色配音 | audio | TTS、声音克隆或其他语音工作流 |

每个绑定项包含 `generation_type_id`、固定或跟随默认的 `workflow_version_id`、能力标签、默认参数覆盖和启用状态。优先级为“镜头临时选择 > 项目默认绑定 > 生成类型默认工作流”。任务一旦创建必须写入实际 `workflow_version_id` 与发布配置版本，后续全局默认变化不得改变历史任务。

项目级绑定 P0 可保存在 `ShortDramaProject.settings.production_bindings`；当需要跨项目模板、查询和审计时再迁移为独立绑定表。禁止把 ComfyUI API JSON、节点地址或密钥复制到项目设置。

#### 4.2.3 工作流语义映射

漫剧模块只生成领域语义，不直接依赖 ComfyUI 节点编号。提交前由 Production Intent 编译器按 `WorkflowVersion.param_schema` 注入：

- `prompt`、`negative_prompt`。
- `image`/`video`/`audio` 类型的 Resource ID。
- `aspect_ratio`、`width`、`height`、`duration`、`seed`、质量档位。
- 首帧、尾帧、宫格、角色参考、场景参考、道具参考等具名素材槽。

参数映射、必填校验、资源权限校验、节点路径检查和 `build_prompt` 编译全部复用现有工作流服务。工作流缺少所需语义槽时，该绑定标记为“不兼容”，不能进入全自动模式。

### 4.3 模型能力卡

视频生成面板内必须实时展示当前“生成类型 + 工作流版本”的能力卡。能力数据来自已发布生成类型配置、参数模板和工作流 `param_schema`，不得在漫剧页面维护第二份硬编码模型表：

- 可用输入模式。
- 是否支持尾帧、多参考图。
- 可选时长、比例和分辨率。
- 当前工作流、版本、输出媒体类型及限制说明。
- 当前可用 ComfyUI 节点和调度状态。

若当前比例、时长或输入模式不受支持，参数映射不完整，工作流未发布，或没有满足能力标签的可用 ComfyUI 节点，生成按钮禁用并直接给出具体阻止原因。供应商密钥和模型文件由对应 ComfyUI 工作流/节点环境负责，漫剧页面不重复收集。

## 5. 项目库与项目创建

### 5.1 项目库页面

实站采用无侧栏、全宽居中的大面积留白、细边框卡片和黑白/米白视觉；顶部从左到右为统计和操作：

- 项目数量、最近 7 天活跃数、素材总量。
- 新建项目主按钮。
- 帮助、系统设置、主题切换。
- 最近工作区：左侧大卡显示最近项目名称、更新时间、角色/场景/道具和项目概况；右侧“快速查找项目”包含搜索、最近 3 个项目、查看全部和系统设置。
- “继续编辑”“新建项目”“浏览全部项目”。
- 全部项目：默认按最近编辑排序的完整项目卡片列表。

项目卡片至少显示标题、描述、角色/场景/道具数、最近编辑、创建日期和删除/更多操作；封面是可选增强，不得作为卡片完整显示的前提。支持打开、重命名、复制、导出、归档/删除。

### 5.2 新建项目

参考实站，点击顶部“新建项目”或空状态按钮后直接创建默认项目，进入项目总览，并自动创建“第 1 集”；创建前不设置强制向导。

- 默认标题为“新建项目 + 时间”，可以在项目内重命名。
- 输出语言、默认目标时长、分镜工作流和视觉风格在项目设置或剧本策划中按需补充。
- 主按钮保持快速创建；“导入整篇小说”和“导入项目工程”作为旁路入口，不阻塞一键新建。

### 5.3 项目总览

源截图中的项目总览包含：

- 项目标题、创建日期、阶段标签和准备度进度条。
- 基础结构准备项：剧本、角色、场景、道具、世界观等。
- “导入整篇小说”“导出整项目”。
- 下一步建议卡：“继续推进创作，世界观可按需再补”，并提供“进入第一集”。
- 统计卡：角色数、场景数、道具数、集数、世界观状态。
- 单集列表：标题、状态、最后编辑时间、完成度、进入工作区。

### 5.4 整篇小说导入

- 支持粘贴正文和上传 `.txt` / `.md`。
- 先解析正文，再按语义、章节和目标时长拆成多集草稿。
- 拆分时继承项目输出语言、目标时长、视觉风格。
- 导入前显示字数/章节估算；导入后显示成功、警告和未识别段落。
- 允许人工调整集边界、标题和顺序；每集可进入正常流程单独细化。
- 大文件使用后台任务，页面刷新后可恢复进度。

## 6. 剧本与故事

页面为左右分栏：左侧“项目配置”，右侧大文本编辑器。

### 6.1 左侧项目配置

- 项目标题输入框。
- 生成分镜模式二选一，按钮文案为“小说生成分镜”“分镜生成分镜”；第二项内部语义为已有分镜模式。切换模式同步更新说明、示例模板、输入提示、校验规则和生成策略。
  - 小说生成分镜：用户没有分镜、只有小说正文、章节、剧情大纲或剧本时使用；系统从故事理解开始完成分场和拆镜。
  - 分镜生成分镜：用户已经自行设计分镜时使用；系统保留用户的镜头顺序、对白、任务动作、镜头备注和叙事意图，只做结构化、缺项补全、素材引用绑定与能力校验，使后续图片和视频具有更强一致性。
- 输出语言下拉框。
- 画面比例：横屏、竖屏；作为后续角色、场景、分镜和视频的项目默认值。
- 目标时长快捷项：30 秒（广告）、60 秒（预告）、2 分钟（片花）、5 分钟（短片）、自定义。
- 目标时长下方实时显示秒数、叙事容量提示，以及按当前视频工作流默认单镜时长估算的镜头数。
- 分镜生成模型下拉；选项来自 comfyui-console 模型注册表，显示模型说明与内部 ID。
- 视觉风格：日式动漫、2D 动画、3D 动画、赛博朋克、油画风格、真人影视、其他（自定义）。
- 视觉风格显示可放大的参考缩略图，并支持上传参考图反推风格。
- 质量控制开关默认开启，校验字段、关键帧结构、素材 ID 与工作流能力。
- 主按钮“生成分镜脚本”。

配置栏独立滚动，主按钮固定在底部。模型选择不复制 BigBanana 的静态列表，而复用 comfyui-console 已配置的文本/多模态模型；图片、视频和语音能力仍通过工作流绑定统一管理。

真人风格模型限制必须明确提示：不支持真人的模型不可选或不可生成；不能依赖生成后失败。

### 6.2 剧本编辑器

- 支持直接粘贴已有剧本。
- 空白状态提示输入故事想法或完整剧本。
- 顶部操作：AI 续写、AI 改写、选段改写、撤回改写；无正文或无选区时对应操作禁用。
- 顶部提供自定义改写要求输入框，并显示当前选区提示。
- 空态按创作模式显示解释、推荐输入和输入提示。
- 小说模式接受连续文本，空态展示故事理解说明和推荐输入类型，不展示分镜格式模板。
- 分镜模式接受逐镜列表、Markdown 表格或结构化 JSON，并识别镜头号、场次、景别、机位、运镜、时长、画面、动作任务、对白/旁白、镜头备注以及素材引用。
- 分镜模式空态并排展示“模板 A · 标准分镜”和“模板 B · 对话驱动”；两者都包含场景标题、分镜编号、画面、动作任务、对白和镜头备注，点击模板可插入可编辑骨架。
- 已有分镜模式不得静默重排、合并或拆分用户镜头；确需调整时生成差异候选，由用户逐项确认。
- 自动保存、字符数、行数、建议上限和保存状态；实站建议单集不超过 8000 字符。
- AI 结果支持“应用、局部应用、放弃、对比”。

### 6.3 参数设置与反推风格

- 参数设置允许随时修改标题、语言、目标时长、分镜模型和视觉风格。
- “反推风格”从用户上传的参考图提取风格提示词，返回可编辑结果。
- 风格结果保存为项目级 Style Bible，后续角色、场景、分镜和视频生成统一引用。

### 6.4 生成分镜脚本

生成结果不是单纯文本，而是结构化拍摄清单：集 → 场次 → 镜头。每个镜头至少包含：

- 镜头编号、标题、景别、机位、镜头运动。
- 画面描述、动作/对白、情绪。
- 推荐时长和视频模式。
- 角色、场景、道具引用。
- 首帧提示词、视频提示词、连贯性说明。

原文说明生成约需 5–10 分钟。复刻版必须用可恢复后台任务，展示阶段进度（解析、分场、拆镜、补全资产引用、校验），并允许失败重试。

任务成功后自动进入“拍摄清单 / Script Manifest”，而不是只显示一段生成文本或弹出候选确认框。拍摄清单是剧本分析结果的正式版本化产物，也是后续素材提取、视觉设定和镜头制作的唯一上游。

### 6.5 拍摄清单结果页

建议路由：`/v2/drama/projects/:projectId/episodes/:episodeId/manifest`。

顶部显示项目名、清单总时长和保存状态。页面左侧分析摘要包含故事梗概、演员表，并可继续展开场景表、道具表；主区按照“场次 → 镜头”纵向展示。

场次字段：序号、空间/地点、子位置、时间、整体节奏和情绪。镜头字段：

- 镜头 ID、景别、机位、运镜和建议时长。
- 画面叙事、动作任务、对白/旁白、情绪。
- 角色、场景、道具引用；未创建的对象标记为待创建素材。
- 画面提示词、视觉风格、镜头运动、构图引导、首帧要求。
- 角色一致性、场景连续性和负面约束。

所有字段均允许人工编辑；AI 原值、用户修改值和生效值要可追踪。重新生成必须新建 Manifest 版本，不覆盖已审核版本。只有清单通过必填字段与素材引用校验后，才能推进视觉设定、镜头设计或全自动模式。

## 7. 全自动模式

入口位于拍摄清单右上角“全自动模式”。

### 7.1 启动前检查

系统统计缺失项：角色图、场景图、道具图、关键帧、九宫格、视频。按“镜头 × 资产类型”展示缺口，并标明会消耗的模型、预计任务数和风险。

### 7.2 模式规划

- AI 对每个镜头推荐“网格分镜”或“关键帧/首尾帧”。
- 用户可逐镜头修改推荐。
- 网格模式可选 4、6、9 格。
- 启动前生成执行清单，并允许排除镜头。

### 7.3 执行顺序

```text
补齐角色/造型 → 补齐场景 → 补齐道具
→ 生成宫格描述/关键帧提示词
→ 人工检查策略（可选）
→ 生成宫格图或首尾帧
→ 串行/限并发生成视频
→ 汇总失败项
```

### 7.4 中断与恢复

- 敏感提示词、真人限制或模型能力不匹配时，只暂停对应镜头，不应终止整个批次。
- 支持暂停、继续、取消剩余任务。
- 已有最终视频的镜头自动跳过。
- 页面展示总进度、当前步骤、成功/失败/跳过数量和失败原因。

## 8. 角色、场景与道具

### 8.1 资产自动提取

拍摄清单确认后，系统从已确认 Manifest 提取角色、场景、道具，并创建项目级草稿实体后进入“角色与场景 / Assets & Casting”。用户必须能添加、编辑、合并重复项和删除误提取项；重新生成拍摄清单不得静默覆盖已确认素材。

### 8.2 角色卡

截图中角色以三列卡片呈现。每张角色卡包含：

- 名称、别名/身份、年龄等概要。
- 主图/造型缩略图。
- 角色详细描述（身份、面貌、发型、服装、体态、气质等）。
- “生成实体/生成角色图”“管理衣橱”“AI 素材推荐/保存到素材库”“上传”等操作。
- 编辑描述、保存到素材库、删除。
- 截图中的“从资产库替换/加入资产库”在复刻版统一为“从素材库替换/保存到素材库”。
- 顶部图片模型选择器复用 comfyui-console 生成类型与工作流映射；画幅继承项目设置，但允许在明确影响范围后切换。
- 每次重新生成、上传或素材库替换都创建新版本；用户明确采用后才更新角色当前版本。

### 8.3 角色衣橱与造型九宫格

- 一个角色可有多个造型，镜头制作时可选择具体造型。
- 点击“服装变体”打开左右分栏弹窗：左侧为基础造型和身份提示词，右侧为已有服装列表与新增表单。
- 新增服装需要角色内唯一名称和视觉描述；生成始终引用基础造型以锁定身份，只改变服装、配饰、妆发和剧情状态。
- 每个服装变体支持重新生成、上传、版本选择、保存到素材库和删除；被镜头引用时必须先完成替换才能删除。
- “造型九宫格”生成同一角色的多角度/多服装参考图。
- 允许手动上传角色造型图，上传后生成缩略图和可选标签。
- 造型可保存到素材库并跨镜头复用。
- 每次重生成形成新版本；用户可设置默认造型。

### 8.4 场景

场景卡结构与角色卡一致：主图、名称、内外景、时间、空间布局、光线、天气、色板、固定物、提示词、生成、上传、从素材库替换、保存到素材库、编辑、删除。场景素材必须能被多个镜头引用，修改时提示影响范围。

场景与道具前端复用同一个 `ProjectAssetCard`：媒体区、标题区、可编辑提示词、生成/上传、素材库操作、删除和版本状态完全一致。场景额外显示子位置、时间和氛围；提示词覆盖空间结构、固定物、陈设、材质、光线、天气、色板与镜头可用方向。场景图片是跨镜头概念素材，而不是某个镜头的最终关键帧。

角色和场景不是生成一张图即自动完成：必须区分待确认、已确认、需修改。进入镜头设计前，拍摄清单引用的每个角色和场景至少要绑定一个已采用素材版本；缺失或生成失败形成阶段门禁。

### 8.5 道具

用于保证跨镜头一致性，例如武器、令牌、信物。道具卡至少有名称、描述、参考图、生成/上传按钮、提示词、保存到素材库和删除。镜头环境可选择多个道具。

道具卡复用场景卡骨架，并增加分类、归属角色、出现范围和连续性说明。未生成状态在媒体区显示类型图标与“生成/上传”；未设置提示词时显示警告，生成前允许用户编辑或请求 AI 生成候选提示词。道具分类至少支持其他、武器、服饰、交通工具、文书和装置。

场景与道具统一使用状态：未配置、待生成、排队中、生成中、待确认、已采用、生成失败、依赖过期。任何生成、上传或素材库替换均创建新版本，用户确认采用后才更新当前版本，并将引用旧版本的镜头标记为依赖过期。

### 8.6 素材库（合并原资产库）

不建立漫剧专属“资产库”页面、表或文件系统。原平台的资产库能力全部合并到 `comfyui-console` 现有素材库，统一使用 `Resource`、`ResourceFolder`、缩略图、预览、回收站和生成溯源。

- 分类/筛选：角色、角色造型、场景、道具、参考图、分镜图、关键帧、视频、音频和成片。
- 漫剧项目通过 Resource 元数据和领域关联记录 `project_id`、`episode_id`、`shot_id`、`character_id`、`scene_id`、`prop_id`、素材用途和版本，不复制媒体文件。
- 项目内可展示“项目素材”虚拟集合；底层仍是同一个素材库，避免同一素材在两个库各存一份。
- 支持搜索、标签、来源项目、复用次数、创建时间和生成工作流筛选。
- 操作统一为“保存到素材库”“加入当前项目”“设为镜头参考”“下载”“查看生成参数”。
- 角色、场景和道具卡只保存领域描述与 Resource 引用，生成图片仍由 Task 输出进入素材库。
- 被引用素材移入回收站前显示受影响的项目和镜头；默认软删除，永久删除前再次校验引用。

## 9. 导演工作台

主页面为镜头卡片网格，右侧打开“镜头详情”抽屉。镜头卡显示镜头编号、镜头类型、九宫格/关键帧预览、描述、视频状态和错误/完成标签。

### 9.1 顶部工具栏

- 页面模式：导演/列表等视图。
- AI 增强提示词开关。
- 全局进度（例如图片 4/35、视频 4/35）。
- 批量生成/全自动模式。
- 镜头筛选：全部、缺环境、缺图片、缺视频、失败、已完成。

### 9.2 镜头详情抽屉

按折叠面板组织：

1. 剧本与台词
2. 场景环境
3. 网格分镜/视觉制作
4. 动作与对白
5. 视频生成
6. 高级工具

抽屉底部固定“下一步：AI 制作/生成视频”和 Agent 辅助入口。

### 9.3 场景环境

大模型自动选择镜头对应的场景、角色和道具，但用户必须逐项检查。支持添加/移除资产、选择角色造型、调整主次关系；缺少引用时展示警告。

每个镜头角色必须保存明确的造型绑定：`基础造型` 或 `服装 · {CharacterVariant.name}`。下拉框只允许选择当前角色已采用且资源就绪的变体；默认值可从上一镜或场次继承，但 UI 必须显示继承来源。

变体切换只影响当前镜头，除非用户显式执行“应用到本场次/后续镜头”。切换后重新编译角色一致性提示词，并将依赖旧造型的宫格、关键帧和视频标记为过期但保留历史版本。

建议新增或确认以下领域关系：

- `CharacterVariant`：`id`、`character_id`、`name`、`description`、`resource_id`、`status`、`is_default`、`version`、`source`。
- `ShotCharacterBinding`：`shot_id`、`character_id`、`variant_id`（空值表示基础造型）、`inheritance_source`、`updated_at`。
- 一个镜头内同一角色只能有一个生效绑定；同一服装变体可被多个镜头复用，不复制素材文件。

## 10. 宫格分镜

### 10.1 4/6/9 宫格

- 支持 4、6、9 格；较短视频推荐 4 或 6 格，避免切换过快。
- 每格包含顺序、景别、机位、画面英文描述和可选中文说明。
- 选择格数后重新规划节奏，不只是裁切同一张图。

### 10.2 先审描述，再出图

点击“九宫格分镜”后先生成逐格描述，用户可修改景别、机位和英文描述；确认后点击“确认并生成图片”。描述生成和图片生成是两个独立版本化步骤。

### 10.3 两种使用方式

1. 整张宫格图作为视频首帧/网格输入。
2. 从宫格中裁出单格，作为独立首帧。

裁切界面需要格线吸附、单格选择、自由裁剪、比例锁定和保存为新关键帧；不得覆盖原宫格。

### 10.4 历史版本

- 保存描述版本和图片版本。
- 允许“重新生成描述”“仅重新生成图片”“回退并设为当前”。
- 镜头卡永远显示当前选中版本；旧版本可预览和删除。

## 11. 视频输入模式与提示词

### 11.1 输入模式

视频生成前必须选择：

- 关键帧模式：首帧；模型支持时可附带尾帧。
- 网格分镜模式：整张 4/6/9 宫格驱动视频，并自动忽略关键帧输入。
- 多参考图模式：首帧或宫格 + 角色/场景/道具参考图。

模式切换必须清晰说明哪些输入会被使用、忽略或自动补齐。可选模式必须根据当前 `WorkflowVersion.param_schema` 的媒体输入槽和已发布能力标签动态产生；例如工作流没有尾帧参数时不得显示“首尾帧”，图片参数数量不足时不得显示“多参考图”。

### 11.2 起始帧

- 显示当前首帧候选缩略图列表。
- 支持 AI 优化提示词、手动编辑提示词、生成、上传和选择当前版本。
- 网格模式下不要求单独首帧，可直接使用宫格图。

### 11.3 镜头拆分

- 镜头可拆成 2–5 个子镜头；源截图提供数量步进器与“2/3/4/5 镜头”快捷项。
- AI 拆分后返回每个子镜头的动作、景别、时长和连续性说明。
- 用户可手工拆分、重新排序、合并或删除。
- 当 8–12 秒无法完整表达镜头时推荐拆分。

### 11.4 视频提示词

- 展示 AI 生成的默认提示词，允许“AI 优化”和铅笔编辑。
- 编辑时保留原始版本；支持撤销、恢复和复制。
- 提示词应包含动作、镜头、角色一致性、场景约束、负向约束和对白/音效提示。

## 12. 视频生成

### 12.1 参数

- 生成类型与 ComfyUI 工作流版本选择；界面可用友好名称表现为“模型/方案”，保存值必须是 `generation_type_id` 和 `workflow_version_id`。
- 横屏/竖屏及具体比例。
- 时长：模型能力动态决定；源文档示例 Sora 2 为 4/8/12 秒，Veo 3.1/3.1 Fast 固定 8 秒。
- 输入模式与参考图列表。
- 是否原生音频、质量/速度档位（模型支持时）。

模型能力必须来自已发布的生成类型配置和工作流参数映射，不可在界面写死上述示例。若 ComfyUI 工作流通过自定义节点封装 Sora、Veo、Seedance 或本地模型，漫剧模块无需感知供应商，只依据能力槽和参数契约工作。

### 12.2 连贯性策略

- 支持首尾帧的模型：可将上一镜头尾帧设为下一镜头首帧。
- 不支持首尾帧的模型：推荐网格模式。
- 多参考模型：首帧/宫格 + 角色 + 场景 + 道具；模型不支持尾帧时自动忽略尾帧并提示。

### 12.3 任务与结果

- 提交后显示现有 Task 的排队、运行进度、耗时、ComfyUI 节点和 `prompt_id`。
- 成功后内嵌播放器、下载、设为当前、重生成、进入剪辑。
- 失败显示可读原因和“修正参数/重试”。
- 每次成功生成形成媒体类型为 video 的 Take 历史版本；支持一键切回旧版本。

## 13. 配音

视频默认可能自带音频；用户仍可生成替换配音。

- 配音模式：旁白/对白。
- TTS 模型、角色声音、语言、情绪和语速。
- 文本编辑、试听、生成、历史版本。
- 可绑定镜头或整集。
- 生成后进入剪辑器替换或叠加，原视频音频必须可静音。

## 14. 成片、预览、剪辑与导出

### 14.1 成片与导出总览

截图中页面包含：项目标题、镜头数、时长、完成度、大型进度条和多个功能卡。

- 预览视频/渲染成片。
- 导出设置：分辨率、格式；源截图示例含 WebM 下载。
- 打开 AI 剪辑。
- 导出项目工程文件。
- 源素材、数据备份、渲染日志。

只有全部必需镜头具备当前视频时才允许正式成片；缺失项以可点击清单展示。

### 14.2 预览视频

- 按镜头顺序临时拼接，供快速审片。
- 显示总时长、镜头边界和缺失占位。
- 支持全屏、倍速、跳转镜头。

### 14.3 AI 剪辑

源截图为标准非线性编辑器布局：

- 左侧媒体/素材列表和搜索。
- 中间预览监视器。
- 右侧 AI 剪辑建议/指令输入。
- 底部多轨时间线、播放头、缩放、轨道控制。

必须支持：

- 将镜头视频、宫格图、音频拖入时间线。
- 裁剪片头片尾、切分、移动、删除、复制。
- 宫格模式自动裁掉开头约 2 秒的静态宫格首帧（具体秒数可调）。
- 替换/拼接配音，调整音量和淡入淡出。
- 撤销/重做、自动保存、预览和导出。
- AI 指令生成剪辑建议；执行前展示改动清单。

### 14.4 导出

- 视频格式至少 MP4/WebM，分辨率、帧率、码率可选。
- 导出任务异步，显示阶段和进度。
- 结果进入现有素材库并可下载。
- 工程导出与视频导出分开，避免用户混淆。

## 15. 数据备份、日志和提示词管理

### 15.1 素材与项目备份（源平台称“资产备份”）

- 下载项目全部源素材（图片、视频、音频、提示词、元数据）。
- 单集工程导出，供他人或另一设备导入继续创作。
- 采用带版本号的 ZIP 清单，导入时校验哈希、重复 ID 和缺失文件。
- 支持“仅数据备份/包含源素材”两种体积档位。

### 15.2 渲染日志

弹窗顶部显示总任务数、成功、失败；列表显示：

- 媒体类型图标、任务摘要、模型、时间、状态、耗时。
- 展开后显示输入参数、目标对象、错误、重试次数、输出链接。
- 筛选：全部/图片/视频/音频、状态、模型、日期、镜头。
- 允许从失败任务跳回对应镜头并带入原参数重试。

### 15.3 提示词管理 / 提示词库

左侧导航“提示词管理”打开页面标题“提示词库”。页面集中查看、检索和编辑漫剧模板以及当前项目的角色、场景、道具、关键帧提示词，但底层应聚合现有数据，不创建第三套提示词表。

#### 15.3.1 数据来源

| 页面分类 | 数据来源 | 编辑结果 |
| --- | --- | --- |
| 模板 | 现有 `AIPromptTemplate` 和可复用的全局 `Prompt` | 系统模板创建新版本；普通用户创建项目覆盖 |
| 角色 | 当前项目 Character/CharacterVariant 的提示词字段 | 更新对应角色或服装版本 |
| 场景 | 当前项目 Scene/Location 的提示词字段 | 更新对应场景版本 |
| 道具 | 当前项目 Prop 的提示词字段 | 更新对应道具版本 |
| 关键帧 | Storyboard/Shot/Keyframe 当前版本的提示词 | 更新对应镜头或关键帧版本 |

现有 `Prompt`/`PromptCategory` 继续作为用户主动收藏和跨项目复用的通用提示词库；`AIPromptTemplate` 继续承担小说分析、改写、拆集、分镜等系统模板。漫剧页面只提供统一聚合视图和项目上下文，不复制两者内容。

#### 15.3.2 页面布局

按截图还原以下区域：

- 标题“提示词库”和说明“集中查看、检索并编辑角色/场景/道具/关键帧的提示词与模板”。
- 右上角统计胶囊：“总条目 N”“当前结果 M”。
- 第一行分类统计卡：模板、角色、场景、道具、关键帧；每张卡显示 `当前结果数 / 分类总数`，当前分类使用强调底色。
- 搜索框支持标题、描述、正文、变量名、角色/场景/道具名称和标签。
- 快捷筛选：全部、模板、角色、场景、道具、关键帧。
- “全部展开”“全部收起”；单卡也可独立展开/收起。
- 搜索、分类、项目和集数变化后同步更新当前结果数，不重新加载整页。

#### 15.3.3 提示词卡片

每张卡至少包含：

- 标题、来源分类、作用说明。
- “默认”“项目覆盖”“已修改”或“用户收藏”状态徽标。
- 可用变量占位符标签，例如 `[panelCount]`、`[dialogueGuardrails]`。
- 等宽字体正文区域，保留换行和缩进；长文本折叠并提供展开。
- 复制、编辑、恢复默认、查看历史版本、定位来源对象。

“恢复默认”仅在存在项目覆盖或自定义版本时可用；未修改的默认模板按钮禁用。恢复操作删除项目覆盖并重新继承当前启用的系统模板版本，不能删除系统模板。

#### 15.3.4 模板编辑

编辑抽屉/弹窗包括：名称、说明、分类、语言、系统提示词、用户提示词、负面提示词（适用时）、变量列表、标签、作用域和版本说明。

- 管理员编辑系统模板时，不原地覆盖 `AIPromptTemplate`，而是创建新版本并停用旧的启用版本。
- 普通用户在项目内编辑默认模板时，保存为项目覆盖；P0 可保存到 `ShortDramaProject.settings.prompt_overrides[template_code]`。
- “另存为通用提示词”写入现有 `Prompt`，并选择 `PromptCategory`；不得改变模板本身。
- 角色、场景、道具和关键帧编辑必须创建/更新对应领域版本，不能只修改聚合页的显示副本。

#### 15.3.5 变量和编译校验

- 模板变量采用稳定的机器标识；界面以标签展示，正文中保留明确占位符。
- 每个模板代码声明允许变量、必填变量、默认值和数据类型。
- 保存前检查未知变量、缺失必填变量、未闭合占位符和空正文。
- 提供“预览编译”，使用脱敏示例数据展示最终提示词；不得触发 AI 请求。
- CreativeJob 或 Production Intent 创建时保存模板 ID/版本、项目覆盖快照、变量输入和最终编译文本，保证可追溯。

#### 15.3.6 多语言

页面语言切换只改变界面和当前模板语言视图，不自动翻译提示词。中英文模板分别保存内容和版本；缺少当前语言时显示回退语言及明确提示，避免静默混用。

## 16. 关键交互与通用组件

### 16.1 媒体选择器

所有图片/视频输入统一支持：上传、本项目素材、全部素材、历史版本；选择后显示缩略图、来源和移除按钮。

### 16.2 版本选择器

角色图、场景图、道具图、宫格、关键帧、视频和配音复用同一版本组件：当前版本、时间、模型、提示词摘要、设为当前、对比、删除。

### 16.3 生成按钮状态

- 正常：显示预计模式和模型。
- 缺输入：禁用并列出缺失字段。
- 能力不兼容：禁用并给出模型限制。
- 执行中：进度、取消。
- 失败：原因、重试、换模型。

### 16.4 自动保存与冲突

文本编辑 800–1500 ms 防抖自动保存；媒体版本切换立即保存。并发编辑时使用版本号/ETag，冲突时让用户选择保留本地、采用远端或对比合并。

## 17. 后端服务划分

本模块采用“漫剧领域服务 + 现有生产基础设施”分层，不重建媒体生成系统：

- Project Service：项目、单集、设置、工程导入导出。
- Script Service：小说解析、拆集、剧本版本、拍摄清单。
- Drama Asset Service：角色、造型、场景、道具及其领域引用；媒体文件继续使用现有 Resource Service。
- Prompt Aggregation Service：聚合现有 Prompt/PromptCategory、AIPromptTemplate 和项目领域提示词，处理项目覆盖、变量校验、反推风格与 AI 优化。
- Production Intent Compiler：把镜头、提示词和参考资产编译为现有工作流 `param_schema` 所需参数，并在创建任务前返回结构化错误/警告。
- Existing Generation Type / Workflow Service：直接复用生成类型、发布配置、工作流版本、参数映射与输出映射。
- Existing Batch / Task / Dispatcher：创建 `source=short_drama` 的 Batch/Task，复用 ComfyUI 节点调度、WebSocket 进度、失败重试和结果回收。
- Take Reconciler：将 Task 输出 Resource 通过 `ShotTaskLink` 回写为镜头 Take；ComfyUI 成功但回写失败时进入幂等补偿。
- Drama Orchestrator：只编排全自动模式 DAG、暂停恢复和镜头级幂等，不直接调用 ComfyUI。
- Editorial Service：预览拼接、时间线、配音替换、最终渲染。
- Existing Task/Audit Service：渲染日志、任务事件、失败诊断和用量统计（不含计费）。

媒体生产调用链必须固定为：

```text
Project / Episode / Shot
→ ProductionIntent（领域语义）
→ GenerationType + WorkflowVersion（现有配置）
→ Batch + Task + TaskResource（现有任务）
→ Dispatcher → ComfyUI Node
→ Resource（现有素材）
→ ShotTaskLink → Take（漫剧领域结果）
```

## 20. 验收标准

### 20.1 主流程验收

1. 新建项目，设置中文、60 秒、3D 动画和分镜模型。
2. 上传一篇 `.txt` 小说，系统拆出多集，人工调整后进入第 1 集。
3. 使用 AI 改写生成候选，应用后生成结构化拍摄清单。
4. 自动提取角色、场景、道具；补充一个角色造型并加入衣橱。
5. 对一个镜头选择 6 宫格，先编辑逐格描述，再生成宫格图。
6. 对另一镜头使用首尾帧，并复用上一镜头尾帧。
7. 为多参考视频选择已发布的生成类型和 ComfyUI 工作流，提交角色+场景+道具 Resource；能力或参数映射不兼容时前端阻止创建 Task。
8. 生成两版视频并切回旧版本；失败任务可从日志重试。
9. 生成替换配音，在剪辑时间线裁掉宫格开头并替换音频。
10. 预览整集、导出成片、下载源素材、导出工程并在新项目中成功导入。

### 20.2 全自动模式验收

- 启动前准确统计缺失资产。
- 用户可逐镜头改模式和宫格数。
- 中途单镜头失败不会中断其他镜头。
- 暂停、刷新页面、重新进入后可以继续。
- 已有当前视频的镜头不重复生成。
- 人工编辑内容不被静默覆盖。

### 20.3 视觉与交互验收

- 亮/暗主题所有页面和弹窗无缺色。
- 左侧阶段导航、中央镜头网格、右侧镜头抽屉的结构与源截图等价。
- 所有生成面板都能在提交前解释输入、模型能力和阻止原因。
- 所有生成媒体都有当前版本、历史版本、来源提示词和下载入口。

### 20.4 comfyui-console 集成验收

- 在现有“生成类型配置”中新建或发布一个图片、视频、语音工作流后，漫剧模型设置无需录入 API 信息即可选择它。
- 项目默认绑定、镜头临时选择和生成类型默认工作流的三级优先级正确，Task 固化实际工作流版本。
- 漫剧提交的图片、视频、语音任务出现在现有任务管理中，并复用节点调度、进度、取消、重试和再检查。
- 输入参考图来自现有 Resource，经 TaskResource 上传到目标 ComfyUI 节点；输出回收到现有素材库并关联正确 Shot/Take。
- 工作流版本缺少必填参数、节点映射、输出映射或所需媒体槽时，Production Intent 编译阶段返回字段级错误且不创建任务。
- 单个 ComfyUI Task 输出多个文件时全部登记为独立 Take；设为采用只改变镜头选择，不改写或删除原 Resource。
- ComfyUI 已完成但 Take 回写暂时失败时，Task 仍保持成功，并由幂等补偿生成缺失 Take。
- 停用生成类型、归档工作流或发布新版本不影响历史 Task/Take 的可追溯性。
- 漫剧模块数据库中不存在重复的工作流、节点、媒体文件或通用任务表。

### 20.5 提示词库验收

- 模板、角色、场景、道具、关键帧五类数量和“当前结果”随搜索、分类、项目和集数正确变化。
- 系统模板、通用 Prompt 和项目领域提示词在同一页面可检索，但编辑分别回写正确的数据源。
- 普通用户编辑默认模板只生成项目覆盖，不修改全局 `AIPromptTemplate`；恢复默认后重新继承当前系统版本。
- 管理员修改系统模板创建新版本，历史 CreativeJob 仍能追溯到旧模板版本和最终编译文本。
- 变量标签、必填校验、未知变量提示和预览编译正确；预览不得提交 AI 或 ComfyUI 任务。
- “另存为通用提示词”写入现有 Prompt/PromptCategory，并立即可在 `/v2/prompts` 中查看。
- 编辑角色、场景、道具、关键帧提示词后，对应领域对象版本更新，聚合页刷新后内容一致。
- 中文/English 切换不会覆盖另一语言模板；发生语言回退时界面有明确标识。

## 22. 基于 comfyui-console 现有底座的适配审查

### 22.1 审查结论

本次实现以 BigBanana 的页面结构、操作路径和业务语义为目标架构。现有 V2.1、V3 不是必须兼容的产品边界，只作为代码与数据能力候选：符合目标的直接复用，部分符合的抽取后改造，不符合或会迫使产品保留旧流程的直接废弃。最终只保留一套面向 BigBanana 的漫剧项目体验。

本节所称 **V2.1、V3，专指当前“短剧项目”模块内部的两代实现**，包括 `frontend/src/v2/features/short-drama/`、`backend/app/short_drama/`、短剧领域模型及其专属 API。它们不代表 `comfyui-console` 整个平台的版本。平台公共底座——GenerationType、Workflow/WorkflowVersion、Batch、Task/TaskEvent、Resource/ResourceFolder、ComfyUI 节点调度、素材库、提示词库和系统配置——不因短剧 V2.1/V3 的取舍而废弃，仍作为 BigBanana 漫剧模块的基础设施。

当前状态可概括为：

- **生产底座成熟可复用**：GenerationType、WorkflowVersion、Batch、Task、Resource、TaskResource、素材目录、ComfyUI 调度、进度、重试和输出回收已经存在。
- **短剧前半程有较多可用实现**：项目、小说导入、AI 分析/改编、分集剧本、角色、角色造型、地点、道具、镜头、素材绑定、Take 审阅可以作为 BigBanana 页面背后的实现基础，但旧页面结构不作为约束。
- **V3 只拆取能力，不保留流程**：连续性、风格、锚点、空间计划、Manifest 等服务经验证后可以拆成 BigBanana 工作台的内部能力；九步门禁、实验入口、未完成占位和不符合参考平台的概念直接下线。
- **后半程尚未形成成片闭环**：基础视频裁剪、拼接已有，但配音编排、字幕、时间线、整集预览、渲染交付、工程备份和全自动恢复仍缺少领域模型与统一界面。
- **迁移目标是替换而不是长期兼容**：旧对象能映射到 BigBanana 对象时迁移并复用；不能可靠映射的旧功能标记 deprecated、从新入口移除，完成数据迁移后删除，禁止形成长期双轨。

复用判定遵循以下顺序：

1. 是否完整支撑 BigBanana 截图和目录中的功能行为。
2. 是否能在不暴露旧 V2.1/V3 流程的前提下作为内部服务使用。
3. 是否与现有 ComfyUI 任务、工作流、Resource 和素材库天然集成。
4. 若需要为保留旧代码而改变 BigBanana 的信息架构、术语或操作顺序，则不复用。

### 22.3 BigBanana 目标事实源与旧数据处理

| BigBanana 业务概念 | 目标事实源 | V2.1/V3 处理 |
| --- | --- | --- |
| 项目基本设置 | `ProjectBrief` 或等价的单一项目设置对象 | 复用已有字段；V3 风格圣经只提取可用内容迁入视觉风格，不成为必经事实源 |
| 剧情场次 | `Scene` | 复用 V2.1；旧 V3 场景台账只迁移能对应到 Scene 的数据 |
| 场景环境 | `Location` | 复用 V2.1；V3 空间图/视图作为 Location 的可选素材或元数据，不保留独立流程 |
| 角色基础档案 | `Character` | 复用；V3 角色锚点字段择优迁入角色生成约束 |
| 角色衣橱/造型 | `CharacterVariant` | 作为 BigBanana 衣橱的目标模型；能可靠映射的 `CharacterStateVersion` 一次性迁入，之后停止双写 |
| 道具 | `Prop` | 复用；V3 道具锚点择优迁入描述、连续性说明和参考素材 |
| 镜头 | `Shot` | ManifestItem、宫格、音频 cue、剪辑条目都引用 Shot，不复制镜头描述 |
| 媒体文件 | `Resource` | Character/Location/Prop/Shot/Take 只保存引用；任何“保存到素材库”不复制二进制 |
| 生成结果版本 | `Take` | 图片、视频、音频都可使用 Take；“采用”只切换选择，不删除旧 Resource |
| 执行记录 | `Task` + `TaskEvent` | 继续复用；CreativeJob 仅承担可用的 LLM/文档后台作业，旧 V3 workflow run 不进入新产品主状态机 |
| 模型与工作流 | `GenerationType` + 固化的 `WorkflowVersion` | 漫剧能力槽仅保存绑定关系，不复制节点、API JSON 或供应商密钥 |

旧表可以在迁移期保留为只读数据来源，但新 BigBanana 页面不得继续双写。每个旧对象必须被归类为“直接复用、迁移后废弃、立即废弃”之一，并在迁移完成后移除无调用路由和服务。

### 22.4 信息架构调整

现有 `/screenplay`、`/world`、`/storyboard`、`/production` 页面中的组件和 API 可以拆取复用，但页面结构以 BigBanana 为准重新组织。旧 `/director` 九步工作台不作为新项目入口，完成可用能力迁移后删除路由。

建议项目内导航固定为：

1. 项目总览
2. 故事与剧本
3. 角色与场景
4. 镜头设计
5. 生成制作
6. 配音与剪辑
7. 成片交付

不再保留“V3 专业导演模式”这一产品概念。BigBanana 导演工作台就是唯一导演入口；连续性检查、场景环境、角色一致性和 Manifest 编译作为镜头详情或生成前检查按需出现，不要求用户走完旧 V3 步骤。

全局页面继续保留：

- 素材中心：素材库、选择器、提示词库、回收站；漫剧页面使用带项目上下文的抽屉或过滤链接。
- 工作流中心与生成类型配置：管理员发布能力；项目只选择已发布版本。
- 任务中心：作为所有漫剧生成的底层运行记录；项目内仅提供过滤后的业务视图。
- AI 模型配置：只管理文本分析/改编使用的 Provider；图片、视频、语音仍由 ComfyUI 生成类型管理。

### 22.5 现有生成链路需要修改的点

1. `ShortDramaProductionView` 当前让用户为一批镜头选择任意 GenerationType。应先选择业务动作（关键帧、宫格、首帧视频、首尾帧视频、多参考视频、TTS），再由项目绑定解析为 GenerationType/WorkflowVersion。
2. `production_service` 当前按参数名猜测 prompt、first/end/pose 等素材，适合兼容旧工作流但不适合作为长期契约。应优先读取发布时保存的语义槽位映射，名称猜测只作为迁移兼容并输出警告。
3. 项目默认、镜头覆盖、生成类型默认的三级优先级必须固定：镜头临时选择 > 项目能力绑定 > GenerationType 默认；创建 Task 时固化实际 WorkflowVersion 和配置版本。
4. 工作流能力由 `param_schema` 与显式 capability 元数据共同决定。若首尾帧、多参考、音频或输出类型不满足，编译阶段阻止创建 Task，并返回可定位到控件的错误。
5. `_resources` 当前可收集镜头及角色/地点参考素材，但多参考的顺序、语义角色和数量上限不能依赖无序 ID 列表。需要 `slot -> ordered Resource[]` 的 Production Intent。
6. 选择现有两个编译实现中更适合 BigBanana 语义槽位的一套作为新 Production Intent 核心，吸收另一套有价值的校验后废弃旧入口；不以维持 V2.1/V3 双兼容为目标。
7. Take 已足以承载历史结果；宫格整图、裁切单格、配音和最终渲染需补 `purpose/variant_kind/parent_take_id` 或等价元数据，才能表达派生链路。

### 22.6 最小数据增量

P0 不建议大规模重建表，优先增加以下可追溯对象：

- `DramaCapabilityBinding`：项目级业务槽位到 GenerationType/WorkflowVersion 的绑定及能力快照。
- `GridStoryboardVersion`、`GridStoryboardCell`：4/6/9 宫格、逐格描述、整图 Resource、裁切 Resource、采用状态和版本来源。
- `AutomationRun`、`AutomationStep`：全自动计划、依赖、状态、重试、关联 CreativeJob/Task 和人工覆盖保护。
- `DialogueCue`、`VoiceBinding`：对白/旁白文本、说话角色、音色、时序、音频 Take 和采用状态。
- `EpisodeDelivery`：整集预览/最终交付的输入快照、渲染 Task、输出 Resource、版本和状态。
- `PromptOverride`：项目级默认模板覆盖、语言、基线模板版本和恢复继承；若初期放入 settings，正式上线前仍需迁移到版本化记录。

P1/P2 再增加非线性编辑所需的 `EditProject`、`EditTrack`、`EditClip`、字幕样式和 RenderSnapshot。基础裁剪与拼接接口不能替代时间线工程，因为它们无法保存轨道、音量、字幕、转场和可重渲染快照。

### 22.7 修订后的实施顺序

#### P0A：先建立 BigBanana 唯一主线

- 建立统一项目壳层和阶段导航。
- 按第 22.3 节确定目标事实源，并产出旧对象“复用/迁移废弃/立即废弃”清单。
- 选定唯一 Production Intent 编译核心，迁入有用校验并停止扩展旧编译入口。
- 实现项目能力槽位绑定和语义参数映射。
- 给任务、素材、提示词查询增加 project/episode/shot 上下文。
- 隐藏旧 V3 导演入口，停止为占位步骤补功能。

#### P0B：跑通“剧本到可选视频”

- 复用导入、剧本、世界和 Shot 编辑。
- 补关键帧/宫格版本对象及 4/6/9 格 UI。
- 动态输入模式、工作流能力校验、Task 创建和 Take 回写。
- 把当前导演步骤 8 的占位替换为真实生产编译界面。

#### P1：跑通“可选视频到整集”

- 配音 cue、角色音色、TTS Take。
- 全自动 AutomationRun、暂停/恢复、跳过与人工覆盖保护。
- 镜头顺序预览、基础音视频对齐、整集渲染和 EpisodeDelivery。
- 工程包导入导出、缺失工作流/素材报告。

#### P2：专业编辑与体验完善

- 多轨时间线、字幕、BGM、转场、AI 编辑指令和可重渲染快照。
- 批量对比、智能返工、失败诊断、代理媒体和大项目性能优化。
- 将连续性、空间和锚点中确有价值的能力做成 BigBanana 工作台的可选工具；删除剩余 V3 页面、路由和无调用服务。

### 22.8 实施前必须解决的阻断项

- 尚未完成旧 V2.1/V3 功能的逐项“复用/迁移废弃/立即废弃”判定及数据迁移脚本。
- 尚未选定唯一 Production Intent 编译核心，两个旧入口仍同时存在。
- 工作流 schema 只有字段类型时，无法可靠表达“首帧/尾帧/角色参考/场景参考”的业务语义。
- 导演工作台仍存在未接入编辑器的步骤，不能作为默认主流程入口。
- 当前没有整集交付对象；直接把若干视频 Resource 拼接后下载，无法满足版本追溯、音频替换和重新渲染。
- 全自动流程没有持久化 DAG 与恢复点，不能用浏览器轮询或单个后台任务代替。

完成 P0A 后再大规模制作宫格和成片页面，可避免新功能继续依赖随后要废弃的旧 V2.1/V3 页面和接口。

“保留”指保留后端能力或领域对象，不代表保留现有页面；“拆取”指复制或重构有用逻辑到新模块后删除旧调用链；“废弃”只针对短剧项目 V2.1/V3 的专属页面、路由、服务和领域对象，必须包含路由下线、停止写入、数据迁移/归档和无引用代码清理四个动作。任何被其他模块共用的平台服务不得随短剧旧模块一起删除。

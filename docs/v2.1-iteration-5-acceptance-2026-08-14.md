# V2.1 第五轮验收记录：角色与世界设定

日期：2026-08-14

## 本轮交付

- 新增角色与世界设定工作台：角色、地点、道具、人物关系四类卡片统一维护。
- 角色卡支持别名、身份、年龄观感、外观锚点、性格、负面约束及草稿/确认状态。
- 角色支持多套造型，维护服装、发型、妆容和适用说明。
- 地点卡支持空间布局、时间天气、光线、色彩和固定物件。
- 道具卡支持外观锚点、适用范围、归属角色和连续性备注。
- 所有角色、地点和道具均可从素材库选择图片、视频或音频作为参考，并可打开预览。
- 从当前剧本版本提取角色、地点、同场人物关系和常见/显式道具候选，候选必须人工确认后才写入。
- 同名人工设定默认保留；选择禁止跳过时接口明确拒绝覆盖，不会静默替换人工内容。
- 候选携带章节/段落来源定位；确认后自动建立场景与角色卡、地点卡的引用关系。
- 剧本工作台新增场景角色多选和地点关联，并纳入自动保存、复制及版本快照。
- 被场景引用的角色或地点禁止删除；素材引用校验用户归属和删除状态。
- 新增素材使用情况查询接口，支持后续素材库展示“被哪些设定使用”。
- 新增 Alembic 迁移 `0011_world_setting_workspace.py`，并补充旧 SQLite 开发库兼容升级。

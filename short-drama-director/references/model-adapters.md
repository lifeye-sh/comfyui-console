# 视频模型适配层 (Model Adapters)

> 各平台能力差异大，本模块统一管理“易变参数”，主规则（`action-previs-15grid.md`、`seedance-render-engine.md` 等）不绑定具体版本。

---

## 一、 适配原则

1. **主规则通用，适配层定制**：题材、镜头、动作、语速、质检等核心规则与具体模型无关；只有“时长上限、参考图语法、负面词支持、音频支持、切镜能力”等属于平台易变参数。
2. **每次投喂前先查本表**：按当前使用的模型选择对应行参数，覆盖到提示词与时间轴。
3. **参数以平台官方文档为准**：本表为经验值，可能随模型迭代变化；拿不准以官方为准。

---

## 二、 常见平台参数速查（经验值，2026-08）

| 平台/模型 | 单次生成时长上限 | 参考图支持 | 负面词支持 | 音频/对白 | 切镜能力 |
|---|---|---|---|---|---|
| **Seedance 2.0** | 约 10~15 秒（视套餐） | ✅ 首尾帧/参考图 | ✅ | 部分支持（对白/音效） | 多镜次可，建议 ≤4 镜/组 |
| **即梦 (Jimeng)** | 约 5~15 秒 | ✅ 图生视频 | 部分 | 可加提示音 | 中 |
| **可灵 (Kling)** | 约 5~10 秒 | ✅ 图生视频/参考 | ✅ | 音效可 | 中 |
| **MiniMax H3** | 约 6~15 秒 | ✅ | ✅ | ✅ 对口型/多语言 | 中高 |
| **通用兜底** | ≤ 10 秒 | 以平台为准 | 以平台为准 | 以平台为准 | 单镜优先 |

---

## 三、 投喂前清单（逐条核对）

- [ ] 该平台的**单次时长上限**是多少 → 单元总时长是否 ≤ 上限？
- [ ] 是否支持**参考图/首尾帧** → 角色资产参考图 + 场景资产参考图均按平台语法挂载？
- [ ] 是否支持**负面词** → Layer 3 负面排除是否可写？
- [ ] 是否支持**对白/音频** → 有对白时该平台如何指定（文字转语音 / 静默留白 / 另配）？
- [ ] 是否支持**多镜次** → 不支持时每组只给 1 镜或拆得更细？
- [ ] 画幅是否支持 16:9 与 9:16 → 按平台能力选择模板。

---

## 四、 失败降级策略（生成不理想时）

按顺序降级，保持叙事完整：

1. **减角色**：群战/多人同框 → 先保主角色单人 + 环境。
2. **减动作**：连续多招 → 简化为“关键一招 + 受力反馈”。
3. **减切镜**：多镜次 → 合并为单镜 ONER 或两镜。
4. **拆单元**：单组超上限 → 拆成更短单元，用 `camera-transitions-6types.md` 的接续状态衔接。
5. **换平台**：本平台能力不足（如不支持对白）→ 换适配平台或改静默留白。

---

## 五、 输入契约（生成前必填项）

| 输入 | 必填/可选 | 默认值 |
|---|---|---|
| 题材与风格 | 必填 | 无 |
| 目标总时长 | 必填 | 180s / 90s / 60s |
| 画幅 | 必填 | 9:16 竖屏（短剧）/ 16:9（大片） |
| 目标平台/模型 | 必填 | Seedance 2.0 |
| 对白是否锁定 | 必填（用户原话不可改？） | 可润色不可删 |
| 动作强度档 | 建议 | R2 商业高燃（默认） |
| 空间/资产信息 | 可选 | 缺失时按“最小锚点 + 通用场景”假设，并在输出中标注假设 |
| 是否直投公开平台 | 建议 | 是 → 自动走安全默认档转译 |

**输出契约**：每组提示词必须包含 ①画幅风格 ②资产锚点 ③时间轴分镜（含时长守恒）④负面排除 ⑤接续状态 ⑥（如有对白）语速自检结果。

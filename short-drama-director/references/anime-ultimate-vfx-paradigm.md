# AI 漫剧·人物大招与视觉巅峰法术提示词范式 (Anime Ultimate & Domain Burst Paradigm)

本规范提炼自行业爆款 AI 漫剧“大招蓄力与法阵爆发”提示词工程（如《人物大招系列》即梦 / Seedance 2.0 16:9 与 9:16 工业模版）。

---

## 一、 15 秒大招三段式节奏结构（默认高燃档）

一条标准的大招高燃提示词应分为三大连续阶段，层层递进，音画共振（默认对应 `action-previs-15grid.md` 的 R3 玄幻大招档；写实题材不强制）：

```
┌──────────────────────────┬──────────────────────────┬──────────────────────────┐
│ 阶段 1：大招蓄力 (0-3s)   │ 阶段 2：法阵展开 (3-8s)   │ 阶段 3：终极爆发 (8-15s) │
│ 特写微距 + 极速环绕升镜   │ 全景拉远 + 空间扭曲畸变   │ 巨型法相/火龙卷 + 爆音终帧│
└──────────────────────────┴──────────────────────────┴──────────────────────────┘
```

### 1. 阶段一：大招蓄力与微距拉升（0~3 秒，抓眼球）
* **镜头运镜**：极低角度微推 $\rightarrow$ 特写悬停 $\rightarrow$ 中景极速环绕拉升 $\rightarrow$ 定格人物全身。
* **微观动作**：手腕猛旋、指尖余火缠成暗角、掌心太古签纹极转、足尖点噬火浪、收焰聚于掌心、青筋暴突、眼眸神光爆绽。
* **特效细节**：掌心凝刃、“主色+副色”双色波涌燃炼、金羽凝结、空气扭曲、碎石浮空。
* **音效设计**：开屏即爆音（尖锐火雷声/破空剑鸣 + 地面低频轰鸣，0.5 秒特写抖动蓄势，瞬间拉满压迫感）。

### 2. 阶段二：法阵展开与空间异象（3~8 秒，造奇观）
* **镜头运镜**：低角度微推 $\rightarrow$ 全景平稳抬升拉远 $\rightarrow$ 俯瞰空间格局。
* **空间动作**：单手擎天/虚空悬浮、身姿沉稳傲慢、尊袍随狂风神风傲然扬动、俯视冷冽。
* **法阵与异象**：亿万符文如火龙盘旋漫天泼洒、空间随阵法剧烈扭曲崩折、千道法纹铺满夜空顶、地面龟裂透出熔岩/雷光。
* **音效设计**：弦乐拉满 + 重音震底，法阵展开伴随漫天雷鸣轰鸣，节奏持续攀升。

### 3. 阶段三：终极爆发与道域镇压（8~15 秒，情绪高潮）
* **镜头运镜**：大广角全景 $\rightarrow$ 极速推向爆发核心 $\rightarrow$ 冲击波定格终帧。
* **终结绝杀**：凝聚十道巨型火龙卷/万剑归宗/黑渊禁区，碾碎漫天虚空，天地恒压无极。
* **音效设计**：重低音音爆轰炸，余音回荡，绝不设平静收尾，以最高燃爆点定格收尾！

## 二、 双色粒子与高级质感配色铁律

1. **双色缠绕原则**：
   * 严禁单色涂抹，必须采用“主色 + 副色”高反差互补或渐变，例如：
     * `赤红 + 暗金`（熔岩尊者、烈阳神明）
     * `玄黑 + 幽紫`（暗夜深渊、魔道至尊）
     * `冰蓝 + 银白`（霜雪剑圣、寒月仙尊）
     * `苍青 + 鎏金`（太古道祖、东方修仙）
2. **画质声明（可选预设，按渲染风格路由）**：
   * **3D 写实/国漫**：`次世代 PBR 真实光照，体积雾弥漫，8K 超高清（若平台支持），材质真实颗粒感，开启低空碎石虚空漂浮宏景`；
   * **2D 动画/二次元**：`高规格 2D 动画渲染，干净线条，粒子密度拉满，背景分层景深`；
   * 不要无条件强制 UE5/8K——不同模型支持度与题材适配不同；若用户指定风格，以风格预设为准。
   * **符文类元素**：默认写成 **不可读的抽象几何符纹/发光纹样**（避免模型生成乱码文字）；仅在用户明确需要真实文字时例外。

## 三、 标准输出模板（以 15 秒大招为例）

```text
人物为主 (三视图)；场景: [上古荒原/云海仙台/废墟夜空, 裂缝涌光, 碎石浮空, 焦土铺满, 极度压迫感]。

分镜1: 大招蓄力 (0-3s): 运镜: 极低角度微推悬停→中景极速环绕拉升→定格全身。动作: @角色 [悬于虚空/脚踏焦土], 手腕猛旋, 指尖[属性元素]缠绕, 掌心凝聚[微观法印/核能量], 苍白面容衬冷酷红瞳, 身姿微沉傲然。特效: 掌心[双色焰流/剑芒]疯狂旋转燃炼, 周围空气剧烈热扭曲, 地面升裂符文裂纹, 低空碎石脱离重力悬浮。音效: 开屏即爆音! 尖锐雷鸣声+低频地脉轰鸣, 0.5s特写抖动蓄势, 瞬间抓眼。

分镜2: 法阵展开 (3-8s): 运镜: 镜头平稳抬升开环绕推远, 俯瞰全景。动作: 单手擎天, 尊袍随罡风狂烈扬动, 俯视苍生。特效: 亿万道[主色+暗金]古符文如狂龙自背后漫天喷洒, 铺满整片夜空, 空间随阵法剧烈扭曲崩折, 环形道纹如光轮层层嵌套旋转。音效: 宏大交响弦乐拉满+重音震底, 法阵铺开漫天雷暴炸响。

分镜3: 终极爆发 (8-15s): 运镜: 大全景急速后拉跟随冲击波向外狂暴扩散。动作: 五指虚按/巨刃挥斩, 引爆整个空间法则。特效: 法阵中心喷涌出十道[巨型龙卷/毁灭光束/虚空断层], 碾碎沿途一切, 冲击波呈海啸状横扫地平线, 地裂千丈。音效: 毁灭级重低音音爆轰鸣, 碎石崩塌声扑耳。节奏持续攀升至最高潮定格终帧!

画质声明(可选): [3D写实] 次世代 PBR 真实光照, 体积雾弥漫, 8K 超高清, 材质真实颗粒感, 开启低空碎石虚空漂浮 / [2D动画] 高规格 2D 动画渲染, 粒子密度拉满。符文一律用不可读抽象几何符纹。
```
